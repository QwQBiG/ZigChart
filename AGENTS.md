# Development agreements

## English

- New auxiliary pane membership must clear maximization in Zig so the added study is visible. Compare active masks before/after configuration; retain order, weights and shared time. Parameter/style edits and price overlays must not clear maximization.

Preserve whole provider candles, including weekly/monthly values from outside the selected dates. Presets end at provider snapshot cutoffs, never the computer clock or a partial candle's future end. Custom ranges use a validated exclusive bar-opening cursor, not candle truncation or an as-of replay boundary; retain it on period changes/retries and pause replay. Latest returns to the current snapshot even after empty/error results; End/time-axis double-click require chart data. Returning stays paused. Cancelling unsubmitted date drafts must not mutate data or viewport.

- Default crosshairs to free movement. Keep OHLC readouts tied to the pointed candle, cursor price tied to pointer height, and saved magnet choices explicit. Close magnets use close regardless of candle direction; settings feedback reports the applied mode, not an uncommitted draft.

- Source code, identifiers, and code comments use English; localized message values may use their target language. Commit and pull request descriptions provide matching English and Simplified Chinese summaries, validation results, and limitations. Issues may use either language. Maintain documentation in English and Simplified Chinese together: keep English filenames and add `.zh-CN.md` counterparts with reciprocal language links and localized internal documentation links. Both versions must retain the same facts, examples, source links, and limitations. Keep this file and the pull request template bilingual in one file; preserve upstream legal notices verbatim in their original language.

Language changes must preserve core/data/interaction state and UTC semantics; unavailable preference storage must not prevent switching.
- Do not add generated-tool attribution to public content.
- Describe current behavior, design reasons and measured results in plain language. State each fact once near its subject. Keep operational constraints precise; omit unrelated feature wish lists, discarded approaches and conversation history from delivery descriptions.
- Keep Zig platform independent: data validation, indicators, viewport and geometry belong in `core/`. Browser networking, input, scheduling, and Canvas drawing belong in `web/`.
- Exchange numeric batches through a versioned Wasm ABI; never call browser APIs from Zig.
- Timestamps are UTC epoch milliseconds. Prices and volume are integer units; instrument metadata defines their scale. Reject unsafe or non-finite values.
- Preserve ordered, unique bars. Replace snapshots, prepend strict older history, and upsert only the current final bar or newer bars. Validate whole batches before mutation.

Preserve count, viewport, locks and drawing anchors. The optional provider correction callback shares subscription lifetime guards; adapters own revision ordering and snapshot races.

- Manual price scaling belongs to the core: preserve time and volume, keep raw ranges transient, and apply the numerical bounds in the architecture contract. Linear spans are 2–4e12 units with endpoints within ±4e12; log endpoints remain positive with a two-unit minimum span. The host owns price-axis gestures, a 4-pixel vertical drag threshold, cancellation, and Auto/Fixed feedback; reset refits vertical ranges without moving time or changing the selected transform.
- Keep regular/logarithmic/percentage/indexed transforms, inversion, forward/inverse coordinates and readable ticks in Zig. Relative bases use the first visible candle center's close and `abs(base)`; zero/missing bases fall back to regular. Nonpositive visible data or range endpoints fall back from true log; nonpositive drawing anchors only invalidate their own projection. Mode changes preserve locked raw ranges and time/volume state; automatic ranges use mode-specific padding. Export requested/effective mode explicitly.
- Preserve ABI v1's 17-value frame rows and 13-value metadata. Copy the additive four-value axis block and at most 16 tick triples before further core calls. Keep version 1 `zigchart.scales` and `zigchart.crosshair` independent. Chart settings reset appearance, series styling and scales while preserving series type, indicators and crosshair preferences; apply/cancel rules cover all three drafts.
- Time-axis gestures claim only the bottom axis left of the price-axis corner, use CSS coordinates and a 4-pixel horizontal threshold, and delegate to the shared core viewport. Rightward drag zooms around the right edge, wheel normalizes delta units and anchors at the pointer, and double-click follows latest. Resolve four crosshair modes from the copied frame, keep snapping pane-local, and never invent future timestamps. Update the bilingual feature map when implemented capability boundaries change.
- Use instrument scales consistently in axes, readouts, and quotes. Host decimal scales are positive safe integers with reciprocals terminating within 20 places; reject unsupported scales. Invalidate subscriptions before cleanup; cleanup errors must not block period switches or disposal.
- Treat Wasm memory views as borrowed. Copy results before retaining them or making another mutating call.
- Use UTF-8 and LF, including PowerShell scripts. Preserve unrelated changes and inspect the complete diff before delivery.
- Pin build tools and dependencies. Verify native core tests, the built Wasm bridge, and actual browser interactions after relevant changes.
- Keep purchased data, credentials, local configuration, binaries, build output, and measurements out of version control.
- Preserve the project's Apache-2.0 LICENSE. License changes require owner approval; adopting third-party implementation requires approval and a license review.

Default to candles only. Built-in MA/EMA/Volume/RSI/MACD/BB retain settings on removal; up to six extra MA/EMA instances have stable slot IDs and are deleted individually. RSI uses 0–100; MACD includes zero and visible components, locks on effective pan and refits with other ranges.

Preserve stable centered-moment arithmetic for narrow spreads at large prices. Enabled bands participate in price bounds/log eligibility without changing pane membership or maximization. Copy additive six-f64 rows [basis, upper, lower, basisY, upperY, lowerY], preserving ABI v1. Appearance version 3 accepts versions 1 and 2, copies their body colors into new border/wick colors, upgrades matching version 1 dark preset colors, and preserves custom chart colors; old chart-wide indicator style fields do not migrate into the independent indicator document.

Update core geometry for the current viewport, ignore resize observations matching committed dimensions, and update displayed text only when it changes. ## 简体中文

- 新增副图成员时，Zig 必须清除最大化以显示新指标。比较配置前后的启用掩码，保留顺序、权重与共享时间。仅修改参数／样式或主图叠加指标不得清除最大化。

- 日期预设和自定义导航放在 `features/range/`：宿主负责 UTC 日历／周期／对话框／加载策略，复用 MarketSession，由 Zig 将时间戳适配到视口。将包含首尾的日期转换为排他结束时间，包含起点所在蜡烛，遵守间距限制，报告无数据／历史不完整／裁剪／错误状态，并拦截过期适配。保留提供方整根蜡烛，包括周／月周期中所选日期之外的数值。预设结束于提供方快照截止时间，不使用电脑时钟或未完成 K 线的未来结束时间。自定义范围采用经过校验的排他开盘时间游标，不截断蜡烛或定义历史回放截止边界；切换周期／重试保留游标并暂停回放。最新在空历史／失败后也能返回当前快照，End／双击时间轴要求图表有数据，返回后保持暂停。取消未提交的日期草稿不得修改数据或视口。

- 十字线默认自由移动。开高低收读数对应指针所在蜡烛，光标价格对应指针高度，保留显式保存的磁吸选择。收盘磁吸不因涨跌改变字段；设置反馈显示已应用模式，不显示未提交草稿。

- 源码、标识符和代码注释使用英文；本地化消息值可以使用其目标语言。提交和拉取请求说明应包含相互对应的英文与简体中文摘要、验证结果及限制。议题可使用任一语言。文档同时维护英文和简体中文：保留英文文件名，增加 `.zh-CN.md` 对应版本，提供双向语言链接，并将内部文档链接指向对应语言。两个版本须保持相同的事实、示例、来源链接和限制说明。本文件和拉取请求模板在同一文件内提供双语；上游法律声明保留原文，不改写或翻译替代。
- 同步维护英文和简体中文界面消息，包括 Canvas 文字、动态状态、无障碍标签和页面元数据。本地化放在浏览器宿主内。切换语言必须保留核心／数据／交互状态和 UTC 语义；偏好存储不可用时也应能切换。
- 不在公开内容中添加生成工具署名。
- 使用直接、具体的语言说明当前行为、设计理由和实测结果，每项事实在对应位置写一次。准确保留使用约束；交付说明不夹带无关功能清单、已弃用方案和聊天过程。
- 保持 Zig 与平台无关：数据校验、指标、视口和几何逻辑放在 `core/`；浏览器网络、输入、调度和 Canvas 绘制放在 `web/`。
- 通过带版本号的 Wasm ABI 交换数值批次；不得从 Zig 调用浏览器 API。
- 时间戳使用 UTC 纪元毫秒。价格和成交量使用整数单位，由交易品种元数据定义缩放比例。拒绝不安全整数及非有限值。
- 保持 K 线有序且时间戳唯一。快照整体替换；前插历史必须严格早于已有数据；增量更新只允许替换当前末根 K 线或追加更新的 K 线。修改状态前先校验整个批次。

- 保留 ABI v1 的 17 值帧行及 13 值元数据。继续调用核心前，复制新增的四值坐标轴块及最多 16 个刻度三元组。版本 1 `zigchart.scales` 和 `zigchart.crosshair` 独立保存。图表设置重置外观、序列样式和坐标轴，同时保留序列类型、指标及十字线偏好；应用／取消规则覆盖三份草稿。
