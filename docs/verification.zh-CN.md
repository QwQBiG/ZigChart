# 验证

[English](verification.md) | [简体中文](verification.zh-CN.md)

本文定义可复现的检查方式，不是已完成运行的记录。每次修改都应报告实际命令、环境、结果和未验证范围；不能从编译或单元测试推断浏览器行为正确。

## 自动化检查

日期范围：覆盖闰日／月末截断、受支持周期选择、排他性结束边界、稀疏时间戳、密度裁剪、未推进的历史分页及取消／重试。浏览器中依次选择一个月、全部和一天；确认实际周期变化，全部到达提供方最早历史，快照截止时间不跳到月底，所有图窗仍对齐，手动平移清除预设选中状态。检查双语界面及日志。

十字线回归：在同一根上涨或下跌蜡烛内，默认／自由模式须跟随多个指针高度，同时保留该根 K 线的开高低收读数。显式收盘磁吸在两种涨跌方向上均须使用收盘价。检查设置入口悬浮提示中的已应用模式、应用／取消、刷新持久化及双语切换；修改默认值时不得覆盖有效的已有保存模式。

针对多均线，将不同 MA／EMA 周期与独立公式比较，覆盖预热、末根修订、历史修正及前插。验证无效配置整批拒绝、关闭槽位、输出复制、自动范围／对数回退，以及相同配置保留锁定范围。浏览器中再添加一条均线并独立编辑，移除原有均线、刷新及切换语言，新增实例的标识／设置应保留。检查六条额外均线的上限，只移除测试实例。基准另设 100,000 根 K 线、八条均线负载，测量末根更新及帧复制，不包含浏览器绘制。

在干净检出中，使用锁定的 Node／npm 版本执行：

```text
npm ci
npm run setup:zig
npm run check:architecture
npm run check:docs
npm test
npm run build
```

`npm test` 运行原生 Zig 测试、构建 Wasm 模块，并针对这个真实模块运行宿主测试。`npm run build` 重新构建 Wasm、检查 TypeScript，并生成 Vite 生产构建。原生引擎测试和 Node 宿主中的 Wasm 测试覆盖不同边界；两者都不执行 Canvas 绘制或浏览器事件。

原生测试显式使用 LLVM（`-fllvm`），同时保留 Debug 安全检查。Zig 0.15.x 原本在 x86_64 Linux Debug 构建中默认使用自实现后端，在 Windows 上默认使用 LLVM；固定后端可避免平台默认值不同。背景见 [Zig 后端发布说明](https://ziglang.org/download/0.15.1/release-notes.html#x86-Backend)。Wasm 生产构建仍采用 `ReleaseFast`；这项选择不改变图表逻辑，也不关闭原生运行时检查。

`npm run check:architecture` 解析 TypeScript 模块引用，拒绝数据层依赖 `data/` 外部、可复用模块依赖 `app/`（`main.ts` 启动入口除外），以及显式相对运行时循环。夹具测试覆盖允许的仅类型循环、禁止的归属／运行时依赖，以及 CLI 成功／失败退出码。计算生成的动态导入和未来路径别名需另行审查；该检查不能替代 TypeScript 或浏览器验证。

`npm run check:docs` 检查八组英文／中文文档、双向语言链接、LF 换行，以及本地链接目标。将 `DOCS_BASE_REF` 设置为提交 SHA 时，还会检查该提交与 `HEAD` 之间的文档改动是否同时包含两个语言版本。CI 在可用时提供这一比较基准。该检查验证结构与配对改动，不判断翻译准确性或语义是否一致；维护者必须将两个版本一起审阅。

应持续覆盖无效／重复／乱序数据、原子拒绝、当前 K 线替换、追加／前插、MA／EMA 初值与预热、完整快照等价性、视口锚点、零成交量、平价／负价格、输出复制和独立模块实例。行情测试应覆盖数据确定性、排他历史游标、回放修订、取消和无效请求。

针对 RSI／MACD，使用小型数值样本核对 Wilder 首个完整周期的平均涨跌初值、持平 RSI 为 50、包括 MACD 信号线在内的完整 SMA 种子、预热 NaN，以及 `histogram = MACD - signal`。将重复末根修订及追加／前插结果与完整重算比较。验证价格／成交量／RSI／MACD 共用横向视口且数据行对齐，覆盖预热值缺失、移除／重新添加及相邻窗调节。确认数据、指标配置和图窗布局变化会使缓存帧失效；仅指针移动复用帧时不得显示过期几何或数值。

周期检查应将聚合 OHLCV 与同一套规范分钟样本比较，包括当前分钟累计快照的替换、小时／日边界、周一开始的周、闰年与平年二月，以及不同长度自然月之间的切换。验证各周期的排他游标、末根未完成标志、初始 49 根月 K 线、不支持的秒级周期拒绝，以及切换周期时回放时钟连续。使用忽略取消请求的适配器模拟快速切换：过期历史、流数据和错误都不能改变新会话。

绘图检查应覆盖历史前插、平移、缩放、调整尺寸和时间戳间隔下的时间锚点投影；整数价格转换；图窗／未来空白拒绝；最上层边线／控制点选择；以及 Wasm 输出复制。宿主检查应覆盖每次提交编辑对应一步撤销、取消预览、撤销／重做分支和上限、锁定几何／删除、周期隔离、文档恢复、错误品种／缩放系数／版本、重复 ID、无效坐标及 256 对象上限。偏好检查应覆盖 JSON 往返、无效指标设置、外观迁移、独立默认值和存储不可用。

宿主本地化检查应覆盖两种语言的消息键及插值参数一致、有效的已保存语言优先、浏览器语言选择与英文回退、偏好存储不可用，以及保留 UTC 语义的数字／日期格式化。这些检查补充对 DOM 和 Canvas 译文的实际浏览器验证。

原生与 Wasm 回归检查应覆盖默认右侧留白、将最新蜡烛平移至绘图区中心、追加时保留所选右侧间距、通过跟随操作恢复默认间距，以及较早视图和历史前插锚点的稳定性。检查短历史边界、空白未来槽位的命中拒绝、已存储 K 线保持不变，以及所有已添加图窗共享的横向位置。

平移比例回归应比较移动前后的同一根保留 K 线：X 必须按预期距离平移，而蜡烛宽度、价格／成交量范围，以及数值未变化部分的 Y 坐标保持固定。覆盖首次请求帧之前平移、松手后再次平移、调整尺寸的映射、会重算 EMA 的历史前插，以及跟随视图和较早视图中的实时修订／追加。验证无效或被边界约束为无变化的平移保留原模式，并验证显式视图定位／缩放／跟随和快照替换恢复自动适配，包括空快照之后的情况。宿主测试应验证 UTC 刻度时间戳在小数平移和任意长度历史前插时保持稳定，右侧存在空白时仍按完整视口确定密度，并随缩放或宽度改变密度。缺失周期不得生成虚构标签。图窗裁剪还需要实际浏览器验证。

价格轴检查应覆盖相对顶部的初始锚点、时间与成交量不变、有限跨度／端点、无效输入、无变化的边界操作，以及重置不移动横坐标。在浏览器中验证纵向移动 4 个 CSS 像素后的上／下拖动、单击、忽略成交量／时间轴、取消、双击重置、平移后的自动／固定反馈，以及两种语言下按钮的上／下方向键。手动比例须在调整尺寸和行情更新后保留，但不跨刷新保存。将短／长周期已预热 EMA 的末根修订与完整重算比较；检查缩放系数 8／32／1e9 的格式和不支持系数的拒绝，以及暂停、周期切换和销毁时订阅清理抛错的行为。

CI 工作流在 Windows、Linux 和 macOS 上执行安装、编译器配置、架构及文档检查、测试和生产构建。各任务记录 Node 的 `process.platform` 和 `process.arch`；结果仅适用于实际采用的运行器架构，因此 arm64 macOS 运行不能证明已覆盖 Intel Mac。不包含部署或发布步骤。本地运行不能证明远程工作流已通过，编译器提供某平台或架构的下载也不能证明已在该平台或架构上实际运行验证。

修正测试应将稀疏历史批次与完整重建进行比较，覆盖所有指标初值和成熟递推状态。拒绝不存在的目标、重复项、错误行及普通增量通道中的历史更新，不允许部分修改。检查前插历史后的修正、缓存失效、固定范围、绘图锚点及订阅取消／错误路径。提供方顺序和真实行情修正竞态仍需使用该提供方做集成测试。

## 浏览器检查清单

启动 `npm run dev`，或在完成生产构建后启动 `npm run preview`。使用浏览器的真实交互方式，并记录浏览器版本、视口尺寸和设备像素比。

1. 确认 `core.wasm` 成功加载，选择一分钟周期，验证加载 500 根样本 K 线且回放初始暂停。没有已保存指标偏好时，应只显示蜡烛，没有指标图例或空成交量副图。通过分析库添加后续检查所需的指标。检查合成数据标识和可见错误状态。最新蜡烛中心应位于绘图区宽度的 80% 处，已添加图窗共用相同右侧留白。其他周期在样本历史不足时可能加载较少 K 线。
2. 在所有已添加图窗上移动指针：十字光标、所选 UTC 时间、OHLC、成交量和指标值必须对应同一根 K 线。确认蜡烛、成交量和振荡指标点横向对齐，预热值仍显示不可用。移入未来空白区域，确认 K 线提示框消失，不展示过期或虚构数值。
3. 在多个指针位置用滚轮缩放，验证未触及边界时保持锚点。向两个方向拖动，并在 Canvas 聚焦时使用左／右方向键、`+`、`-` 和 `End`。比较拖动前、拖动中和拖动后同一根未变化的蜡烛：高度和宽度必须固定，松手后价格／成交量范围仍须固定，保留的 UTC 刻度标签必须随其 K 线移动而不改变时间戳。向更新数据的方向平移，直到最新蜡烛居中，确认不能继续超出此位置，且更多空白不会提高刻度密度。缩放、**最新**和 `End` 必须重新适配纵轴；**最新**和 `End` 还必须恢复约 20% 的右侧留白。单独测试短历史，因为零下界可能限制位置。
4. 手动加载更早历史，并通过导航接近左边缘触发自动加载。检查数量、时间戳锚点、时间标签稳定性、请求串行化和历史结束行为。平移锁定的纵轴范围必须在加载后保持。更早的 EMA 初值导致指标变化属于预期行为。
5. 启动回放，观察当前 K 线替换及随后新 K 线追加。确认追加保留所选的右侧留白，单独替换不会移动视图。平移后，价格和成交量继续更新时范围必须保持锁定；超出范围的值必须被裁剪在各自图窗内，直到重新适配。暂停并确认停止发送；恢复并确认序列继续。回放期间平移离开最新数据边缘，确认视图停留在原处，直到执行**最新**或 `End`。
6. 分别添加／移除 MA、EMA、成交量、RSI 和 MACD，核对图例、副图空间、提示框，以及重新添加时的设置恢复。修改一个指标的参数／样式，确认其他指标不变，包括 RSI 参考线和 MACD 信号线／柱状图颜色。同时显示四个图窗时，拖动各相邻分隔条，检查键盘／重置操作、共享横向对齐和裁剪；移除图窗并确认分隔条随之更新。调整窗口大小时不应出现中间清空帧。调整尺寸保留锁定范围；周期／添加状态变化重新适配纵轴，不移动横向视口。
7. 暂停回放、进行一次平移并切换指标后，在 **English** 和 **简体中文** 之间切换。检查控件、样本标识、OHLC／提示框文字、Canvas 成交量标签、状态、文档标题／语言／描述，以及无障碍标签。已加载 K 线、视口、锁定比例和指标可见性必须保持不变。数字和日期应采用所选语言的格式，时间仍使用 UTC。在回放中和历史请求未完成时重复切换；进度须继续，不能重复订阅、重启请求，或在请求完成后显示旧语言消息。
8. 手动选择语言后刷新，确认偏好被保留。在新的浏览器配置中检查偏好语言识别和英文回退。禁止偏好存储时，确认仍能正常启动和切换。在窄视口中检查两种语言，确保控件不被裁切、文字不重叠，且语言选择器可访问。
9. 单独制造启动失败，例如阻止 Wasm 请求，确认显示可见的本地化错误，而不是没有说明的空图。错误可见时切换语言，检查消息更新，控制台仍保留原始诊断信息。还应检查历史请求失败及其重试状态。恢复请求后重新加载并确认成功。
10. 选择分钟、小时、日、周和月周期，核对标签、OHLCV、UTC 边界、指标重算及未完成周期状态。初始月度样本包含 49 根 K 线。在加载历史和回放时快速切换；过期结果不得覆盖所选周期，模拟时钟须保持连续，原先运行的回放须在加载完成后恢复。指标可见性保持不变。刷新并检查手动选择的周期偏好。
11. 点击蜡烛主体／影线显示序列中心控制点，再点击控制点打开设置；达到 4 个 CSS 像素的拖动不得打开设置。检查空白点击／`Esc` 取消选择及标题／`Enter` 备用入口。在**商品代码**中测试主体／边框／影线各自的可见性和上涨／下跌颜色，以及实心／空心蜡烛。在**版面**中测试主题、背景／网格颜色、网格及末价线可见性。**应用**提交草稿；**取消**、关闭和 `Esc` 丢弃草稿，包括主题／重置改动。应用设置必须保留数据、平移范围、指标设置和回放。检查版本 1／2 向版本 3 迁移时保留自定义颜色。收起／打开自选侧栏，并在 1280×720 和 360px 宽度下检查两种语言，确保控件可用、图表可见。
12. 创建全部九种图形，选择边线／控制点，拖动整体和端点，修改样式，锁定／解锁并删除。锁定对象仍可选中，但不能移动或删除。验证 `Esc` 取消未完成编辑、每次完整拖动只占一步撤销，以及撤销／重做恢复几何与样式。进行平移、缩放、调整尺寸、前插历史和回放：锚点必须保持在其数据坐标上。未来留白和成交量图窗必须拒绝新锚点。验证双方向射线、仅向右延伸的水平射线、垂直线裁剪到价格图窗、重合／屏外锚点，以及锚点离开视口后仍可选中的延伸部分。检查线段缓冲区复制、四种价格变换及反转。激活工具后切换语言，检查其分类、标签和选中状态。
13. 切换周期后返回，核对绘图隔离。刷新并检查有效几何恢复，且不恢复撤销／选中状态。在隔离样本中检查存储不可用及本地文档损坏时的设置和绘图行为；不得覆盖用户的浏览器数据。未知版本及不匹配品种／缩放系数不得加载不兼容图形。确认 256 对象上限有可见状态，且仍可通过受支持的编辑撤销。
14. 完成整个流程后检查控制台和网络错误，区分主动注入的失败与意外错误。另行检查销毁清理与浏览器前进／后退行为；单张截图不能验证生命周期清理。

触摸／双指缩放、屏幕阅读器可用性、长期流稳定性、采购行情、重连，以及 Chrome／Firefox／Safari 兼容性矩阵，需要分别验证。不能仅因桌面指针输入正常就宣称已支持这些能力。

基准线呈现需验证首根可见／固定参考、直线／阶梯、独立颜色、坐标反转、单点和范围外参考，以及未来空白不填充。在浏览器中检查应用／取消、空固定价格拒绝、点击线条／填充选择，以及通过控制点或 Enter 重新打开设置。刷新并切换语言，核查版本 1 迁移及版本 2 恢复；切换序列类型时保留已有指标、绘图和视口。

验证图窗排列时，将价格主图移至副图下方，核对标题、绘图、刻度和分隔线随之移动。最大化 RSI／MACD，平移后还原，确认共享时间及原有比例；移除正在最大化的指标，确认其余图窗恢复。刷新应保留顺序、清除最大化。用两种语言检查标签和状态反馈，确认隐藏的价格控件不能接受输入。

斐波那契回撤需检查 0／1 端点、反向、线性与对数插值、高价格窄范围精度、坐标反转、关闭比例线、延伸部分命中和缓冲区复制。编辑比例后失焦或按 Enter，再刷新，确认已提交数值恢复。无效数值不得修改对象。添加／删除比例、修改单个对象样式、锁定／解锁、撤销／重做及切换语言。检查价格图窗重排／隐藏时的裁剪、拥挤标签省略，以及设置面板滚动时关闭按钮仍可见。

触摸导航检查通过真实 Wasm 桥接验证同时改变间距／中点、范围锁定、阈值／无变化、退化间距、松指提交、第三触点等待及调整尺寸取消。控制器测试使用模拟触点，不能证明浏览器指针捕获的事件顺序或物理设备可用性。应在触摸硬件上测试单指选择／平移与绘图，并分别中途加入第二触点；跨不同图窗捏合，先后释放任意触点，加入第三触点，通过周期／尺寸变化中断，确认不误选、不意外提交绘图、不跳位。另行验证桌面鼠标、滚轮及坐标轴行为。声称触摸兼容性前须记录设备、系统与浏览器。

## 测量

基准脚本另外在 100,000 根保留 K 线和 1,400×750 绘图区上投影 256 个斐波那契对象，每个启用 24 级。预热 10 个样本，再报告 31 个样本，每个执行 30 次；包含桥接校验、数值传递及比例输出复制，不包含 Canvas 绘制和交互延迟。

构建 Wasm 后运行 `npm run benchmark`。其 JSON 输出描述保留 100,000 根 K 线、指标周期 20 和 500，以及宽 1,400 个 CSS 像素的绘图区：请求的 2,000 个槽位被限制为约 233.33，生成 234 个投影行。负载包括快照、2,500 根历史前插、通过桥接与预打包数值输入修订末根 K 线、帧、256 个绘图的投影及指针转换。单独的延伸线负载投影 256 个等量混合的垂直线、射线、双向延长线和水平射线，包含锚点及裁剪线段的复制。输出包含运行时／操作系统／CPU 与构建产物元数据、实际负载，以及 31 个单次操作平均毫秒耗时样本的中位数／p95；准备工作不计时。测量范围是 Node 宿主中的 Wasm 与桥接 CPU 工作，不包含 Canvas、网络、浏览器合成、输入延迟或实际显示帧率。检查脚本，只比较相同负载与测量边界。

浏览器的**绘制**指标是当前设备最近最多 90 次重绘的滚动均值，包含核心几何计算、Canvas 命令提交和所选 K 线的 DOM 更新。它不包含呈现／合成，也不代表 FPS 或端到端延迟。提示信息中说明了这一范围。

开展浏览器性能工作时，记录硬件、操作系统、浏览器版本、视口尺寸、设备像素比、保留和可见 K 线数量、绘图数量、所选周期、更新频率、构建模式、预热方式、样本量和精确的测量边界。分别测量初始加载、冷启动／缓存后的周期聚合、历史前插、最新 K 线更新、仅移动指针的重绘、绘图编辑、缩放和平移。若要将耗时归因于布局、渲染、垃圾回收或掉帧，应使用浏览器性能追踪。

在宣称优于另一构建或产品前，必须比较相同样本和负载。原始测量记录应保存在已忽略的 `measurements/` 或仓库外，在审阅说明中提供有意义的环境和结果。本检查清单不代表任何性能门槛，也不宣称优于竞品。
