# 上游能力覆盖

[English](upstream-coverage.md) | [简体中文](upstream-coverage.zh-CN.md)

本清单将学习参照固定为官方 [Lightweight Charts v5.2.1](https://github.com/tradingview/lightweight-charts/releases/tag/v5.2.1)，提交 [`b2ce010e4ad59f6556c9ed60e2b2b30feccdd2d1`](https://github.com/tradingview/lightweight-charts/tree/b2ce010e4ad59f6556c9ed60e2b2b30feccdd2d1)，于 2026-10-05 核对。下文源码路径均相对此提交。[功能范围](feature-map.zh-CN.md)描述已实现行为；[架构](architecture.zh-CN.md)定义职责和数值契约。

比较范围包括库本体、官方插件／指标示例和教程类别。**已覆盖**表示所述 ZigChart 行为存在，不表示 API 兼容。**已实现**表示所述范围内的工作已经交付。**部分覆盖**表示已实现的子集。**进行中**表示正在实施、仍待交付验证。**计划实现**表示需要开发。**专用扩展**表示已盘点，留待适用场景。

ZigChart 学习行为和交互方式，保持独立实现。数据、指标、坐标和共享视口由 Zig 负责；浏览器输入、网络、界面和绘制由宿主负责。本清单不构成导入上游代码或品牌资源的授权。

## 工作台边界

TradingView 的[产品比较](https://www.tradingview.com/charting-library-docs/latest/product-comparison/)区分开源绘制库、Advanced Charts 及托管组件。Lightweight Charts 不提供行情数据或内置指标目录。其示例提供部分集成方式，并不构成 TradingView 网站展示的完整交易工作台。

ZigChart 的品种选择、自选表／报价、周期菜单、指标库、绘图编辑器、历史回放、日期导航、双语对话框、本地文档、全屏及 PNG 控件属于浏览器应用。后续对象管理、收藏、上下文操作及工作区模板应扩展对应功能模块。脚本／策略保留既有入口；Python 执行、回测及经纪商／订单集成仍在 Web MVP 约定之外。
