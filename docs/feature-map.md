# Chart feature map

[English](feature-map.md) | [简体中文](feature-map.zh-CN.md)

This document defines ZigChart's implemented chart boundary and the remaining extension work. It uses the official Lightweight Charts 5.2 documentation as a feature taxonomy, checked on 2026-09-21. The comparison concerns capability categories, not API compatibility, identical behavior, or measured performance parity. ZigChart implements its chart independently through Zig → WebAssembly → TypeScript → Canvas 2D.

Lightweight Charts is a chart library, not the complete TradingView website or TradingHero workbench. It does not supply market data or built-in indicators; applications provide those capabilities. TradingView's [product comparison](https://www.tradingview.com/charting-library-docs/latest/product-comparison/) distinguishes it from Advanced Charts and hosted widgets. No external chart implementation or branded assets are included here.

## Library-level capabilities

**Implemented** means available within the stated scope. **Partial** means a usable subset exists. **Pending** means the capability is not implemented; it is not a promised delivery date.

| Category | Status | ZigChart scope and remaining boundary |
| --- | --- | --- |
| [Series types](https://tradingview.github.io/lightweight-charts/docs/series-types) | Partial | Candles, hollow candles, OHLC bars, close-based line, area, and baseline; volume columns in their own optional pane. Generic histogram data and custom-series registration are pending. |
| Series appearance | Implemented | Independent candle bodies/borders/wicks, rising/falling colors, line width and straight/step paths, area colors, light/dark themes, and grid/last-price visibility. This is the documented settings subset, not the complete upstream option set. |
| [Price modes](https://tradingview.github.io/lightweight-charts/docs/api/enumerations/PriceScaleMode) | Implemented | Regular, positive-only logarithmic, percentage, indexed to 100, inversion, readable ticks, auto fitting and anchored manual scaling. Fallback and reference rules are specified below. |
| [Crosshair modes](https://tradingview.github.io/lightweight-charts/docs/api/enumerations/CrosshairMode) | Implemented | Free, close magnet, hidden and nearest OHLC; separate color/width/line-style preferences and horizontal/vertical visibility. No crosshair synchronization across chart windows. |
| [Mouse scaling](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/HandleScaleOptions) and navigation | Partial | Plot pan and pointer zoom; separate price/time-axis drags; wheel zoom and keyboard navigation. Price-axis double-click refits; time-axis double-click follows latest. Two-contact pinch and midpoint translation use the same viewport; physical-device/mobile-browser verification is pending. Kinetic scrolling and long-press crosshair tracking are pending. |
| [Panes](https://tradingview.github.io/lightweight-charts/docs/panes) and scales | Partial | Up to four built-in panes: price plus optional Volume, RSI, and MACD. Adjacent dividers resize their pair within one shared time viewport. All four panes can move up/down and temporarily maximize/restore. Arbitrary panes, moving studies among panes, additional independent price axes and multiple chart windows are pending. |
| [Series data](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/ISeriesApi) | Partial | Validated snapshots, strictly older historical pages, current-bar replacement, newer-bar appends, explicit atomic corrections to loaded timestamps, and deterministic replay. Historical insertion/deletion, timestamp changes and market-data persistence are pending. The current feed is synthetic. |
| [Extension APIs](https://tradingview.github.io/lightweight-charts/docs/plugins/intro) | Pending | No public primitive/custom-series plugin API or upstream plugin compatibility. Internal modules have bounded responsibilities; arbitrary studies/panes require an explicit versioned output contract. |

## Application capabilities

These are ZigChart host features rather than claims about what Lightweight Charts includes.

| Capability | Status | Scope |
| --- | --- | --- |
| Workbench and editing | Partial | Full-viewport chart, toolbar, drawing rail, editable settings, resizable watchlist/quote sidebar and English/Chinese interface. Four clearly labeled deterministic sample instruments can be selected from the symbol picker or watchlist; per-symbol precision, drawings and fixed baselines remain isolated. Only the active instrument has loaded quotes. Real symbol discovery and multi-symbol quote subscriptions are pending. |
| Chart images and fullscreen | Implemented | Toolbar preview and PNG download of visible panes, committed drawings, indicator legends and localized instrument/period/latest-loaded-bar/sample/UTC labels; crosshair, selection, editing previews and workbench controls are excluded. Images remain frozen and are bounded to 8,192 pixels per side and 16 million pixels total. Native fullscreen includes dialogs and reports browser support/failure. |
| Historical bar replay | Partial | Choose/reselect a candle, play/pause, next bar, 0.25×–10× speeds and return to current data. A shared cutoff survives period changes and excludes future values from partial coarse bars. The sample supplies deterministic partial snapshots; real feeds require the optional replay capability. Replay persistence, multi-chart replay and trading simulation are pending. |
| Date navigation | Implemented | Bottom-left 1D/5D/1M/3M/6M/YTD/1Y/5Y/All presets plus a calendar dialog (`Alt+G`) for one UTC day or inclusive start/end dates. Automatic readable resolution, targeted historical snapshots and shared Zig time fitting; whole candles can extend past either date boundary. Explicit empty/partial/density/error feedback. Historical browsing pauses replay; the Latest button returns to the current snapshot, including after empty/error results. Exchange-session calendars and intraday time selection remain pending. |
| Indicators | Partial | MA, EMA, Volume, RSI, MACD, and Bollinger Bands plus six optional additional MA/EMA instances; all absent by default. Periods 1–500, independent styles, RSI reference levels, MACD signal/histogram colors, and BB multiplier/band/fill settings. Multiple oscillator/BB instances, further studies and user-defined indicators are pending. |
| Drawing objects | Partial | Horizontal/vertical lines, horizontal rays, trend segments, rays, extended lines, rectangles, two-anchor Fibonacci retracements with up to 24 styled ratios, and single-anchor plain text. Text has multiline wrapping, font/style/background/border settings and full-box selection. Grouped tools, data-space anchors, dragging, independent edits, locks, deletion, undo/redo, local saving and PNG export. Broader tools, screen-fixed/rich text, inline editing, templates and future-time anchors are pending. |
| Temporary measurement | Implemented | Price-pane ruler with two clicks or a drag, plus Shift shortcut. Signed price/percentage change, bar distance, inclusive count/volume and actual UTC elapsed time use loaded anchors and Zig projection. Zero-base percentages and unsafe volume totals are unavailable. No persistent range object, undo entry, PNG export, auxiliary-pane measurement or inferred tick/pip counts. |
| Data integration | Partial | Typed provider boundary, history/subscription lifetimes and supported synthetic periods. Purchased feeds, entitlements, reconnects, exchange calendars and adjustments are pending. |
| Persistence | Partial | Versioned local preferences and drawings per period. Indicator documents migrate from version 1/2/3 to 4 with BB disabled; layout documents migrate from version 1/2 to 3, retaining existing settings. Market data, replay clock, undo history and complete workspaces are not restored. |
| Scripts, strategies and trading | Pending | Library categories are explicit unavailable states. No Python runtime, script editor/execution, backtest engine, order model, broker integration or live trading. |

## Behavioral contracts

- Modes and inversion preserve locked raw price ranges, the time viewport, indicator-pane ranges and auto/fixed state. Automatic price ranges use mode-specific padding. Auto/Fixed resets fitting while retaining the selected transform. Effective horizontal zoom and Latest retain their documented refitting behavior.
- Relative modes use the first visible candle center's close. Percentage uses `(price - base) / abs(base) * 100`; indexed values add 100. Zero or unavailable bases fall back to Regular. Panning can change the reference labels without changing the locked raw range.
- True logarithmic projection requires positive visible OHLC, enabled warmed-up price overlays and range endpoints. Separate RSI/MACD panes do not affect this price-mode requirement. Invalid data/ranges temporarily use Regular and show mode feedback. A nonpositive drawing anchor only prevents that object from projecting.
- Crosshair snapping stays within the active pane: line/area/baseline use close, Volume uses volume, and RSI/MACD use the nearest valid indicator value at the selected candle. Warm-up `NaN` values are unavailable and cannot attract snapping. Hidden mode preserves readouts; future blank space has no invented timestamp. Crosshair styles are independent of chart settings and indicators.
- Time-axis drags start after 4 CSS pixels and anchor at the right plot edge; rightward movement magnifies. Wheel input normalizes pixel/line/page deltas and anchors at the pointer. All gestures use the same core viewport.
- Chart settings edit appearance, series and scale drafts. Restore defaults preserves series type and resets those drafts; it does not reset indicators or crosshair preferences. Apply commits, while cancel/close/Esc discards.
- RSI defaults to 14 changes, seeds mean gains/losses from the first full set, then uses Wilder smoothing; a flat seed yields 50. Its pane stays at 0–100 and reference levels are display-only. MACD defaults to 12/26/9 with full-period SMA seeds for its EMAs; the histogram is `MACD - signal`, and its pane includes zero. These are local initialization contracts, not a promise of another platform's exact values.
- BB uses a full-period close SMA and population standard deviation (divisor `N`), default 20 bars and multiplier 2. Unwarmed values remain NaN. Its three tracks share the price axis, participate in bounds/log eligibility and preserve pane membership/maximization. One independently styled BB instance is available; alternate source/basis types, offsets and independent indicator timeframes are pending.
- All enabled panes share one horizontal mapping and frame schedule. Adding Volume, RSI or MACD clears maximization to show the new pane, retaining order, weights and time; parameter/style edits and price overlays retain maximization. Adjacent-divider drag begins after 4 CSS pixels; Up/Down moves 8 CSS pixels and Home/End reaches permitted limits. Double-click restores that pair's default proportions, preserving its combined size and other panes. Each visible pane gets at least 64 CSS pixels when space permits; insufficient height is shared equally.
- Version 4 `zigchart.indicators` preserves valid version 1/2/3 settings and extra averages, adding disabled BB defaults; version 1/2 have no extra averages, and version 1 also gains disabled RSI/MACD. Extra averages have stable slot identities, independent settings and copied core outputs on the shared price axis. Removing an extra deletes its instance; removing a built-in indicator retains its settings. Version 3 `zigchart.layout` stores identity-based `paneWeights` and a validated `paneOrder`, migrating version 1/2 with default order. Maximization is transient; removing the maximized study restores all remaining panes.

See [architecture](architecture.md) for the unchanged frame rows, additive copied pane/indicator/axis buffers, numerical bounds and ownership rules, and [verification](verification.md) for reproducible checks. Formula references are listed in [references](references.md). Feature presence alone establishes neither browser coverage nor a performance result.
