# 图表功能范围

[English](feature-map.md) | [简体中文](feature-map.zh-CN.md)

本文列出 ZigChart 已实现的功能与后续扩展，以 2026-09-21 核查的官方 Lightweight Charts 5.2 文档作为分类参考。ZigChart 采用 Zig → WebAssembly → TypeScript → Canvas 2D 实现，具体行为和接口见下文。

Lightweight Charts 提供图表绘制与交互，行情数据、指标和工作台由宿主应用提供。TradingView 的[产品对比](https://www.tradingview.com/charting-library-docs/latest/product-comparison/)说明了 Lightweight Charts、Advanced Charts 和托管组件各自的用途。

## 图表库层面的能力

**已实现**表示在所述范围内可用；**部分实现**表示已有可用子集；**待实现**标记后续扩展内容。

| 类别 | 状态 | 当前行为与扩展内容 |
| --- | --- | --- |
| [序列类型](https://tradingview.github.io/lightweight-charts/docs/series-types) | 部分实现 | 蜡烛、空心蜡烛、OHLC 柱、基于收盘价的折线、面积与基准线，以及独立可选图窗内的成交量柱。通用直方图数据及自定义序列注册待实现。 |
| 序列外观 | 已实现 | 独立蜡烛主体／边框／影线、涨跌色、线宽和直线／阶梯路径、面积颜色、明暗主题及网格／末价线可见性。这是已记录的设置子集，并非上游全部选项。 |
| [价格模式](https://tradingview.github.io/lightweight-charts/docs/api/enumerations/PriceScaleMode) | 已实现 | 常规、只接受正数的对数、百分比、指数化至 100、反转、易读刻度、自动适配及带锚点的手动缩放。回退与基准规则见下文。 |
| [十字线模式](https://tradingview.github.io/lightweight-charts/docs/api/enumerations/CrosshairMode) | 已实现 | 自由、吸附收盘价、隐藏及最近 OHLC；独立的颜色／宽度／线型偏好及水平／垂直线可见性。尚无多图窗口间十字线同步。 |
| [鼠标缩放](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/HandleScaleOptions)与导航 | 部分实现 | 绘图区平移与指针缩放、独立价格轴／时间轴拖动、滚轮缩放及键盘导航。双击价格轴重新适配，双击时间轴跟随最新。双触点缩放及中点平移使用同一视口；物理设备／移动浏览器验证待完成。惯性滚动及长按十字线追踪待实现。 |
| [图窗](https://tradingview.github.io/lightweight-charts/docs/panes)与坐标轴 | 部分实现 | 最多四个内置图窗：价格主图及可选的成交量、RSI、MACD。相邻分隔线只调整对应两窗，共用同一时间视口。四个图窗均可上移／下移，以及临时最大化／还原。任意图窗、跨图窗移动指标、更多独立价格轴及多图窗口待实现。 |
| [序列数据](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/ISeriesApi) | 部分实现 | 经过校验的快照、严格更早的历史页、当前 K 线替换、新 K 线追加、已加载时间戳的显式原子修正及可复现回放。历史插入／删除、时间戳变更和行情持久化待实现，当前数据流为合成样本。 |
| [扩展 API](https://tradingview.github.io/lightweight-charts/docs/plugins/intro) | 待实现 | 没有公共图形基元／自定义序列插件 API，也不兼容上游插件。内部模块职责有边界；任意指标／图窗需要明确的版本化输出契约。 |

## 应用层能力

下列是 ZigChart 宿主功能，不代表 Lightweight Charts 自带这些能力。

| 能力 | 状态 | 范围 |
| --- | --- | --- |
| 工作台与编辑 | 部分实现 | 全视口图表、顶部工具栏、绘图工具栏、可编辑设置、可调尺寸的自选／报价侧栏及中英文界面。品种选择器或自选表可切换四个明确标识的确定性样本，分别隔离精度、绘图和固定基准价；仅当前品种加载报价。真实品种检索及多品种报价订阅待实现。 |
| 图表图片与全屏 | 已实现 | 顶部入口预览并下载 PNG，包含可见图窗、已提交绘图、指标图例及本地化品种／周期／最新已加载 K 线／样本／UTC 标签，不包含十字线、选择状态、编辑预览及工作台控件。图片内容保持固定，每边不超过 8,192 像素、总计不超过 1,600 万像素。浏览器原生全屏包含对话框，提供不支持／失败反馈。 |
| 历史 K 线回放 | 部分实现 | 选择／重选蜡烛、播放／暂停、下一根、0.25×–10× 速度及返回当前数据。共享截止时间跨周期保留，未完成大周期 K 线排除未来值。样本提供确定性局部快照，真实数据源需要实现可选回放能力。回放持久化、多图回放和模拟交易待实现。 |
| 日期导航 | 已实现 | 左下角 1天／5天／1个月／3个月／6个月／今年／1年／5年／全部预设，以及用于单个 UTC 日期或包含首尾日期范围的日历对话框（`Alt+G`）。自动选择清晰周期、直接加载目标历史快照，并由 Zig 统一适配时间；保留的整根蜡烛可能跨越任一日期边界。明确显示无数据／历史不完整／密度限制／错误。浏览历史暂停回放，最新按钮返回当前快照，在空历史／失败后也可使用。交易所交易时段日历及日内时间选择待实现。 |
| 指标 | 部分实现 | MA、EMA、成交量、RSI、MACD、布林带，以及六条可选额外 MA／EMA 实例；默认全部不添加。周期为 1–500，样式独立，可设置 RSI 参考线、MACD 信号线／柱状图颜色及 BB 倍数／轨道／填充。振荡指标／BB 多实例、更多指标及用户自定义指标待实现。 |
| 绘图对象 | 部分实现 | 水平／垂直线、水平射线、趋势线段、射线、双向延长线、矩形、最多 24 级独立样式比例的双锚点斐波那契回撤及单锚点纯文本。文字支持多行换行、字号／样式／背景／边框设置及整个文字框选中。工具分组、数据坐标锚点、拖动、独立编辑、锁定、删除、撤销／重做、本地保存及 PNG 导出。更多工具、固定屏幕位置／富文本、图表内直接编辑、模板和未来时间锚点待实现。 |
| 临时测量 | 已实现 | 价格图窗标尺支持两次点击或拖动及 Shift 快捷方式。有符号价差／百分比、K 线间隔、含首尾数量／成交量及真实 UTC 历时使用已加载锚点和 Zig 投影。零基准百分比及不安全成交量合计显示不可用。不创建持久化范围对象或撤销记录，不进入 PNG，不支持副图测量或推断 tick／pip 数量。 |
| 数据接入 | 部分实现 | 类型化提供方边界、历史／订阅生命周期及受支持的合成周期。采购行情、权限、重连、交易所日历及复权待实现。 |
| 持久化 | 部分实现 | 带版本的本地偏好及按周期保存的绘图。指标文档从版本 1／2／3 迁移至 4 且 BB 关闭，布局文档从版本 1／2 迁移至 3，保留已有设置。行情、回放时钟、撤销历史和完整工作区不恢复。 |
| 脚本、策略与交易 | 待实现 | 分析库分类明确显示不可用状态。没有 Python 运行时、脚本编辑／执行、回测引擎、订单模型、券商接入或实盘交易。 |

## 行为约定

- 模式与反转保留锁定的原始价格范围、时间视口、指标副图范围及自动／固定状态。自动价格范围使用各模式的留白规则。自动／固定重置适配，同时保留所选变换。有效横向缩放和最新继续采用已有的重新适配行为。
- 相对模式使用首根中心可见 K 线的收盘价。百分比为 `(price - base) / abs(base) * 100`，指数化在此基础上加 100。基准为零或不可用时回退为常规。平移可改变基准标签，而不改变锁定的原始范围。
- 真实对数投影要求可见 OHLC、已启用且预热完成的价格叠加指标及范围端点为正。独立 RSI／MACD 副图不影响此价格模式要求。无效数据／范围临时使用常规，并显示模式反馈。非正绘图锚点只阻止该对象投影。
- 十字线吸附保留在当前图窗内：折线／面积／基准线使用收盘价，成交量使用成交量，RSI／MACD 使用所选 K 线处最近的有效指标值。预热 `NaN` 值不可用且不参与吸附。隐藏模式保留读数，未来留白不虚构时间戳。十字线样式独立于图表设置和指标。
- 时间轴拖动在 4 个 CSS 像素后生效，以绘图区右端为锚点，向右移动放大。滚轮统一像素／行／页单位并锚定指针。所有手势使用同一核心视口。
- 图表设置编辑外观、序列及坐标轴草稿。恢复默认保留序列类型并重置这些草稿，不重置指标或十字线偏好。应用提交，取消／关闭／Esc 丢弃。
- RSI 默认使用 14 次变化，以首个完整集合的平均涨幅／跌幅初始化，再使用 Wilder 平滑；平坦初值取 50。副图固定为 0–100，参考线仅影响显示。MACD 默认周期为 12／26／9，各 EMA 使用完整周期 SMA 初值；柱状图为 `MACD - signal`，副图范围包含零。
- BB 使用完整周期的收盘 SMA 与总体标准差（除数为 `N`），默认 20 根、倍数 2。未预热值保持 NaN，三条轨道共用价格轴、参与范围／对数可用性判断，保留图窗成员及最大化。支持一项独立样式 BB，其他数据源／中轨类型、偏移及独立指标周期待实现。
- 所有启用图窗共用横坐标映射和帧调度。添加成交量、RSI 或 MACD 会清除最大化以显示新副图，保留顺序、权重和时间；仅改参数／样式及主图叠加指标保留最大化。相邻分隔线拖动在 4 个 CSS 像素后生效，上／下方向键每次移动 8 个 CSS 像素，Home／End 移至允许边界。双击恢复该相邻组合的默认比例，保留合计大小和其他图窗。空间允许时每个可见图窗至少 64 个 CSS 像素，高度不足时均分。
- 版本 4 的 `zigchart.indicators` 保留有效版本 1／2／3 设置及额外均线，补充关闭的 BB 默认值；版本 1／2 不含额外均线，版本 1 还会补充关闭的 RSI／MACD。额外均线具有稳定槽位标识、独立设置及复制后的核心输出，共用价格坐标轴。移除额外均线删除该实例，移除内置指标保留其设置。版本 3 的 `zigchart.layout` 按图窗标识保存 `paneWeights` 及经过校验的 `paneOrder`，版本 1／2 以默认顺序迁移。最大化为临时状态；移除正在最大化的指标会恢复所有剩余图窗。

帧行、复制后的图窗／指标／坐标轴缓冲区、数值边界及所有权规则见[架构](architecture.zh-CN.md)，测试方法见[验证流程](verification.zh-CN.md)，公式来源见[参考资料](references.zh-CN.md)。
