# 架构

[English](architecture.md) | [简体中文](architecture.zh-CN.md)

## 职责划分

```text
MarketDataSource（浏览器宿主）
        | 标准化数据批次
TypeScript 桥接 <---- 浏览器输入与帧调度
        | Wasm ABI v1
Zig 引擎：数据 + 指标 + 视口 + 几何
        | 数值帧批次
Canvas 2D 渲染器 + DOM 标签（浏览器宿主）
```

`core/engine.zig` 不依赖浏览器；它组合负责共享 MA／EMA 计算及有界额外实例的 `averages.zig`、RSI／MACD 递推状态的 `oscillators.zig`、滚动价格轨道的 `bollinger.zig`、共享图窗几何的 `layout.zig` 和价格变换的 `price-scale.zig`。`core/wasm.zig` 通过 C 兼容 ABI 暴露操作。`web/src/chart/bridge.ts` 负责模块创建、数值编解码、错误转换和结果复制。行情适配器处理提供方行为，渲染器绘制 Zig 提供的几何数据。浏览器负责网络、事件、设备像素比和动画调度。

Canvas 2D 是当前渲染后端，没有必须替换它的要求。硬件加速由浏览器管理，不设置应用层开关。后续宿主可以复用引擎并自行提供绘制和输入能力，无须向核心引入浏览器 API。

工作台负责组装这些模块；功能模块不持有行情订阅或独立图表视口。

`data/contracts.ts` 定义 `Bar`、`Instrument`、`HistoryPage`、`MarketDataSource`、`MarketReplay` 和 `ReplayState`。数据模块仅依赖其他数据模块，包括类型依赖。`chart/types.ts` 和 `data/replay.ts` 为已有调用方保留类型再导出；新提供方直接导入规范类型。这样可避免行情代码依赖绘制或应用组装。

`app/chart-input.ts` 持有绘图区交互状态，并在事件发生时通过 getter 读取当前核心、帧及绘图编辑器。它将计算委托给已有核心和功能控制器，不创建另一个视口或数据会话。取消及销毁时清理手势和事件监听器。价格轴／时间轴控制器仍在 `chart/`，应用组装仍在 `app/workspace.ts`。

`npm run check:architecture` 检查显式相对运行时导入／再导出循环，将所有数据导入限制在 `data/` 内，并禁止可复用模块导入 `app/`。`main.ts` 是唯一的启动入口例外。完整的仅类型声明不产生运行时边；计算生成的动态导入和未来路径别名需另行审查。模块解析和类型检查仍由 TypeScript 编译负责。绘制层可组合功能渲染器，这项依赖是有意设计的。

Canvas 序列实现属于 ZigChart。产品布局和公开的图表行为仅作工程参考；运行时不嵌入其他图表库，也不引入上游渲染器源码。所有呈现类型使用同一份已复制的 Zig 帧，不另外维护图表模型。

## 数据与指标状态

每个引擎最多保留 100,000 根按时间排序的 K 线。修改数据或视口状态前，会验证整个输入批次。全量替换、严格向前追加历史、当前 K 线替换／新 K 线追加，以及已加载时间戳修正，是独立操作。修正先原子校验目标，再从最早变更位置重算后缀；保留时间、锁定范围、图窗权重及 K 线数量。具体范围与修订行为见[数据契约](data-contract.zh-CN.md)。

MA 和 EMA 各自使用 1 至 500 的整数周期，初始值为 20。MA 为其周期内收盘价的算术平均值。EMA 周期为 `N` 时，以首个完整 `N` 根 K 线的平均值为初值，随后使用 `alpha = 2 / (N + 1)`，不依赖 MA 周期。各自在前 `N - 1` 根 K 线上不可用，以 `NaN` 导出；渲染器跳过这些值。指标输出使用浮点单位，保留均值的小数部分。

六个额外均线槽位复用 `averages.zig` 中的递推，各自保存类型（关闭／MA／EMA）及周期。整批配置在修改前校验，只重算变化的启用槽位；相同配置保留锁定范围，成员／参数变化重新适配但不移动时间。关闭槽位跳过更新。历史修正重算变更后缀，前插重建初值，快照保留配置。启用值通过共享价格变换参与自动范围及对数可用性判断。

六个历史结果数组预留 4,800,000 字节，最大 2,002 行的固定帧缓冲区预留 192,192 字节。不引入逐次调用分配或内存增长。启用掩码非零时，关闭槽位导出 NaN。六个全部关闭时，帧缓冲区已过期、不得读取，桥接省略其复制。原有 MA／EMA 数组继续计算，以兼容 ABI v1 的数值查看。这是有界扩展，不是任意指标插件系统。

`configure_indicators(ma_period, ema_period, mask)` 原子校验周期及 0–7 的启用掩码（MA = 1、EMA = 2、成交量 = 4）。默认均未添加。周期变化只重算对应指标；更改周期或添加状态会恢复纵轴自动适配，保留横向视口。完全相同的配置不产生变化。只有已添加的叠加指标参与自动价格范围计算。未添加副图不占高度，由启用图窗共享释放的空间；帧行及 13 值元数据布局保持不变。

`core/bollinger.zig` 管理一项可选的收盘价布林带。完整 `N` 根窗口中，中轨为 SMA，总体方差为 `sum((close - basis)^2) / N`，上下轨为 `basis +/- multiplier * sqrt(variance)`。周期是 1–500 的整数，倍数是 0.1–10 内的有限数，默认 20／2 且指标关闭。前 `N - 1` 行为 NaN，周期为 1 时三轨数值相同。启用轨道参与共享价格范围及对数可用性判断，下轨非正可能触发已记录的常规回退。BB 是主图叠加指标，配置既不创建副图，也不改变最大化。样式留在宿主内，不得改变计算输入。

有界中心矩树最多 512 个叶节点，合并中心化的均值／方差，避免平方价格和相减，规避高价格窄价差中 `E[x²] - E[x]²` 固有的相消误差。重算时重建前置窗口，再逐个替换变化成员；关闭 BB 跳过计算，相同配置保留锁定范围。桥接复制与帧行对齐的六值 `[basis, upper, lower, basisY, upperY, lowerY]`；价格图窗隐藏时保留原值，坐标为 NaN。已有 ABI v1 行与元数据不变。

`configure_oscillators(rsi, fast, slow, signal, mask)` 在修改前独立校验 1–500 的整数周期、`fast < slow` 和 0–3 的掩码（RSI = 1、MACD = 2）。默认周期为 14 和 12／26／9，默认均关闭。`oscillators.zig` 跳过关闭指标的计算；启用或修改参数时重算受影响的指标。相同配置不产生变化；变化后重新适配纵轴，保留时间视口。

RSI 在索引 `N` 处使用最初 `N` 次收盘变化的平均上涨／下跌幅作为初值，随后采用 Wilder 平滑 `(previous * (N - 1) + change) / N`。结果为 `100 - 100 / (1 + gain / loss)`；两项均为零时取 50，仅下跌均值为零时取 100，仅上涨均值为零时取 0。前 `N` 根不可用。RSI 无量纲、纵轴固定 0–100，可编辑参考线仅影响显示。

MACD 为快 EMA 减慢 EMA，两者都用完整周期 SMA 初始化。首个值位于 `slow - 1`；信号 EMA 在 `slow + signal - 2` 处以最初 `signal` 个有效 MACD 值的均值初始化。直方图等于 MACD 减信号，不乘二。三者均保留价格单位的小数部分。不可用值及坐标为 `NaN`。修订复用前一根递推状态，同一根的多次更新不会重复累积。历史前插可能改变 RSI／MACD 初值及可见结果，与 MA／EMA 一样。

全量快照替换或历史数据前插，会从最早保留的 K 线开始重新计算指标。因此，加载更早历史会改变 EMA 的初值，也可能改变已显示的 EMA 值；这是预期行为，不代表行情价格被修订。该操作也可能补齐先前不可用的 MA／EMA 值。替换最新 K 线时，从该索引开始，使用前一根的 EMA 重新计算，避免多次更新同一根 K 线时重复累积。追加新 K 线只重新计算发生变化的后缀。

EMA 重算仅在受影响的后缀包含初值时，对最初 `N` 个收盘价求和。已完成预热后的末根修订使用已存储的前一 EMA，不重复计算初值和。绘图投影及指针转换请求共享帧元数据，不再生成另一批蜡烛行；其坐标契约保持不变。

## 坐标与交互

视口由可含小数的起始 K 线索引和槽位跨度组成，下限为 10，上限为 `clamp(plotWidth / 6, 10, 2000)`。布局宽度变化后，宿主在使用几何数据前，以扣除价格轴的当前 CSS 绘图区宽度调用 `resize_plot(width)`。绘图区至少宽 60 像素时，这使相邻蜡烛中心至少相隔 6 个 CSS 像素；更窄时仍保留最少 10 个槽位。K 线在逻辑坐标中等距排列，时间戳存在间隔时也相同。核心对蜡烛、成交量、指标线和命中检测使用同一套横坐标映射。除所选跨度外，一帧还可能包含边缘处部分可见的 K 线。

默认跟随视图将最新蜡烛的中心放在绘图区宽度的 80% 处，右侧预留约 20% 的绘图区。向更新数据的方向平移时，最多可以将该中心移至绘图区宽度的 50% 处。设保留数量为 `count`、视口跨度为 `span`，默认起点为 `max(0, count - 0.5 - span * 0.8)`，最大起点为 `max(0, count - 0.5 - span * 0.5)`。最小起点为零，因此历史数据较少时可能无法达到这两个精确位置。上述位置基于绘图区坐标，不包含宿主的坐标轴边距。

空白区域仅表示视口空间，不生成未来时间戳或虚构 K 线。价格图和成交量图共享同一段空白区域。对于保留数据之外的槽位，命中检测返回 `-1`；指针位于该区域时，宿主隐藏 K 线提示框。

默认图窗顺序为价格（0）、成交量（1）、RSI（2）、MACD（3），省略未添加指标。所有图窗共享横向边界，各自拥有纵轴。价格自动适配可见最高／最低价及包括 BB 在内的已启用主图叠加指标；成交量从零到可见最大值；RSI 固定 0–100；MACD 包含零及可见主线、信号线和直方图，并增加边距。价格变换／反转不影响副图值。几何使用 CSS 像素，浏览器应用设备像素比和标签格式。

首次有效平移会捕获**移动之前**视口的两个纵轴范围，即使宿主尚未请求过帧。后续平移保留这些范围：共同可见的蜡烛只横向移动，高度和宽度不变。松开指针、前插历史、修订或追加实时 K 线，都继续锁定范围。调整窗口尺寸会改变像素几何，但保留锁定的价格和成交量范围。无效平移，以及被边界约束到当前起点的平移，不改变纵轴模式。公开 `set_view`、`follow`、有效缩放和全量快照替换会恢复自动适配。**最新**和 `End` 跟随当前数据集，或将历史快照替换为当前快照。已经达到边界、无法改变跨度的缩放输入会保留锁定范围。

`core/layout.zig` 定义间距与启用图窗堆叠。正数相对权重默认为 `[0.74, 0.26, 0.26, 0.26]`，未启用图窗的权重保留。启用图窗各自至少分配 64 个 CSS 像素；可用绘图区高度小于总最小高度时均分。`resize_pane(upperId, deltaPixels, height)` 只调整该图窗及下一个启用图窗，保留其他图窗的权重及高度。从最小高度约束释放时，相邻两窗总权重可能变化，以保持其他图窗高度。正增量扩大上方图窗。旧 `set_pane_split` 保留价格／成交量 0.30–0.85 的契约。调整高度保留时间及锁定范围，所有图窗在同一调度帧内生成并绘制。

首次有效平移还会锁定移动前的 MACD 范围。后续平移、数据更新、历史及尺寸调整保留它；重置／缩放／跟随／配置变化时与其他自适应范围一起重新适配。RSI 保持固定。副图坐标和刻度由 Zig 生成，包括未吸附的十字线数值转换。每个图窗单独裁剪，锁定范围之外的值不会进入其他图窗。

纵轴锁定时，数据和指标仍继续更新。新进入视口或更新后的值可能超出范围，直到显式重新适配。渲染器将蜡烛和指标线裁剪到价格图窗，将成交量柱裁剪到成交量图窗，防止越界几何进入另一图窗。纵轴锁定属于引擎内部状态，不改变 ABI v1，也不改变任何行或元数据布局。

宿主使用所选周期的稳定 UTC 序号，从真实 K 线时间戳中抽取时间标签。固定周期采用声明的时长，周周期以周一为起点，月周期采用自然月序号，不使用固定毫秒近似。它根据完整视口跨度和像素宽度选择便于阅读的槽位步长，再将标签选择锚定到这些序号。因此，平移时已有标签随蜡烛移动，不会从首个可见行重新选择标签起点；改变右侧空白或前插数据不会改变所选步长。缩放和宽度变化可以改变标签密度。该抽样既不虚构未来时间戳，也不提供交易所交易时段日历；缺失槽位保持无标签。

缩放保持指针所指的逻辑位置，视口触及边界时除外。前插历史数据会移动逻辑起点以保持当前所查看的 K 线，仍受相同边界约束。如果追加前最新数据边缘已在视口内，视口起点会增加本次追加数量，从而保留用户已有的右侧留白。平移到更早历史后的视图保持锚点不变。仅替换当前 K 线不会移动视口。**最新**或 `End` 恢复默认约 20% 的右侧留白。

`scale_price(factor, anchor_fraction)` 围绕从价格图窗顶部量起的比例锚点，只调整价格范围；系数大于一时放大。核心保留时间坐标与成交量范围。线性缩放将原始价格跨度限制在 2–4,000,000,000,000 个单位，端点限制在 ±4,000,000,000,000 内。对数缩放在对数空间中进行，原始端点限制在 1e-9–4,000,000,000,000 内，并保留至少两个单位的跨度。到达边界时，最小跨度或端点限制优先于精确保留锚点。无效系数／锚点和未变化的跨度不产生修改。`reset_scale()` 解除纵轴锁定，不改变时间及已配置的坐标变换，`scale_is_auto()` 报告适配状态。已有的有效横向缩放、最新、快照替换及指标配置重新适配行为保持不变。

`chart/price-scale-controls.ts` 只负责宿主事件。它在捕获阶段接管右侧价格轴，纵向移动达到 4 个 CSS 像素后，将增量系数与初始锚点传给核心；向上拖动放大。双击及自动／固定按钮恢复纵轴适配，按钮上的上／下方向键围绕价格图中点调整比例。绘图区手势、成交量轴和时间轴保持独立。按钮反馈跟随核心模式，包括由平移产生的锁定。

`chart/time-scale-controls.ts` 只接管 `meta[12]` 以下、`meta[11]` 左侧的底部时间轴，排除价格轴交角。横向移动达到 4 个 CSS 像素后，向右拖动通过 `zoom(factor, 1)` 围绕绘图区右端放大。滚轮输入统一像素／行／页单位，并以指针占绘图区宽度的比例为锚点。双击调用 `follow()`，恢复默认右侧留白。指针捕获、取消和悬停属于宿主，不引入第二个视口或依赖设备像素比的坐标。

`chart/touch-navigation.ts` 观察第一个绘图区触点，在两个触点形成手势时接管。它负责触点标识、捕获、阈值及取消，不拥有视口。移动事件合并至已有绘制周期，正常松指时最后提交一次。双指欧氏距离控制比例，横向中点提供前后锚点分数。距离或中点变化达到 4 个 CSS 像素才开始导航；触点间距小于 8 像素时重新建立基准，不缩放。两个触点均须从绘图区开始，可分处不同图窗；坐标轴保留独立手势。

新增 `transform_view(factor, from, to)` 通过核心限制后的跨度和锚点分数，计算 `newStart = oldStart + from * oldSpan - to * newSpan`。有效缩放重新适配范围；跨度不变或达到边界时，位移委托给平移并保留范围锁定。无效输入不产生影响。历史与实时更新沿用既有视口规则。双指接管取消绘图预览及单指选择；松指／取消或出现第三个触点后，等待剩余触点全部释放，避免误触或误拖。调整尺寸、切换周期及显式取消会丢弃待处理输入。不引入惯性、长按追踪、独立图窗视口或双指专属持久化状态。

### 时间范围导航

`features/range/` 负责 UTC 日历边界、受支持周期选择、预设工具栏／日期对话框及异步导航。日历入口和 `Alt+G` 打开单个完整 UTC 日期或包含首尾日期的范围草稿，应用时转换为 `[from, to)`。取消尚未提交的草稿不加载数据或改变视口。起点对齐到所属蜡烛，终点裁剪到提供方快照截止时间。按蜡烛开盘时间选择，保留提供方整根 OHLC；周／月 K 线可能包含请求起点之前或终点之后的日期。预设仍结束于提供方当前快照，核心不采用电脑时钟或交易所日历假设。

自定义导航使用 `MarketSession.open(period, before)`，直接获取开盘时间严格早于范围结束时间的首批 500 根快照，仅在需要时追加更早页面。经过校验的排他 `historyBefore` 游标在切换周期和首批重试时保留；它不截断蜡烛，也不定义历史回放截止边界。浏览历史使旧订阅失效、清除待恢复回放状态，并禁止向不完整的历史序列直接追加远处的当前 K 线。最新将历史快照替换为当前快照并保持暂停，其按钮也能从空历史／加载失败中恢复；图表有数据时，End 和双击时间轴提供相同的返回操作。提供方 `asOf` 时钟与请求的历史游标相互独立；历史响应缺少可选的 `asOf` 时保留已知当前截止时间，不从旧 K 线重新推导。迟到响应不能跨越会话代次，范围代次阻止手动导航后的过期适配。最多追加 199 个更早页面以遵守核心容量，未向前推进的分页显式失败。

控制器复用会话和已有共享视口。新增标量导出 `fit_time_range(from, to)` 由 Zig 二分查找 `[from, to)` 内的已加载时间戳，适配对应逻辑范围及常规右侧留白，并恢复纵轴自适应。非法／空范围返回 -1 且不改变视图，完整适配返回 0，密度裁剪返回 1。留白可能显示其他已加载 K 线，不隐藏数据；无需新增缓冲区或分配。宿主区分空范围、可用历史不完整、密度裁剪和错误；全部接受提供方可用的历史起点。缺失交易时段保留缺口，不虚构 K 线。

### 历史 K 线回放

`data/replay.ts` 定义可选的 `MarketDataSource.replay` 能力，管理独立的排他截止时间及可用终点，提供 `seek`、`reset` 和可取消的 `advance`。普通历史 `before` 只选择 K 线开盘时间，不能截断 OHLC 或建立回放截止边界。回放期间全部历史和聚合采用源截止时间，包括未完成的大周期 K 线。样本支持确定性的模拟四分之一分钟快照，不代表还原市场逐笔；聚合缓存只接纳完整结束的日数据。

`MarketSession` 管理播放／暂停、单步、速度和取消。单步完成当前所选周期或追加下一根，以可用终点为上限；自动单步在上一步计算结束后等待 `1000 / speed` 毫秒，速度为 0.25、0.5、1、2、5、10。切换周期在同一截止时间重新加载；切换或销毁前使订阅、计时器和待完成单步失效。`features/replay/controls.ts` 只呈现状态。起点选择使用任意可见图窗的共享时间映射，包含所选蜡烛至 `min(periodEnd, availableEnd)`。关闭面板会暂停并保留该位置；退出重置数据源、加载当前数据并保持暂停，最新／End／双击时间轴仍停留在启用中的回放快照内。缺少该能力的数据源显示不可用操作。Zig 继续基于标准化 K 线计算指标和视口几何，不新增 ABI 或第二套图表模型。

回放启用时，导航按钮显示为**回放位置**，跟随保留的截止时间；返回当前数据须使用**退出回放**。

### 价格变换与刻度

`core/price-scale.zig` 负责价格正向／逆向变换及刻度生成。模式为 0 常规（`normal`）、1 对数、2 百分比、3 指数化至 100，反转独立配置。`configure_price_scale` 保留时间视口、成交量范围、自动／固定状态及已锁定的原始价格范围；自动范围按所选模式的留白重新计算。正值自动对数范围使用乘法留白 `max(log1p(1 / minRawPrice), logSpan * 0.08)`，确保平价或宽幅数据的下端点也保持正值。OHLC、已添加指标、绘图投影、指针转换和价格读数使用同一核心变换。浏览器格式化标签、显示请求／实际模式，不另行重建非线性比例。

百分比和指数化采用中心位于视口内的首根 K 线收盘价为基准，排除左边缘仅部分可见的 K 线。基准为 `b` 时，百分比为 `(price - b) / abs(b) * 100`，指数化为 `100 + percentage`。基准为零或不可用时，实际模式临时回退为常规。负基准通过 `abs(b)` 支持。平移可能改变基准及标签，但继续保持锁定的原始范围和仿射像素映射。

对数模式为只接受正数的真实对数变换。可见 OHLC、已添加且完成预热的指标或原始范围端点中存在非正值时，该帧实际模式回退为常规，同时保留用户请求的偏好。仅绘图锚点非正时，该图形无法投影，不改变整张图的模式或自动范围。无效投影返回 `NaN` 或无效图形几何。高价格的窄范围使用 `log1p`／`expm1` 保持数值稳定性。

刻度采用便于阅读的 1／2／2.5／5／10 步长；跨度较大的对数范围使用按十进制数量级生成的候选值。核心最多输出 16 个刻度，约束像素间距，并分别导出原始价格、投影 y 和显示值。相对刻度显示值无价格单位，常规／对数价格标签使用品种缩放系数。不论坐标模式如何，原始 OHLC 与指标值保持原有单位。

### 十字线呈现

`features/crosshair/` 基于已复制的帧解析交互，通过共享覆盖层 Canvas 绘制。模式为自由移动（`normal`，默认）、吸附收盘价（`magnet`）、隐藏及最近 OHLC（`magnetOHLC`）。折线／面积／基准线在两种吸附模式下使用收盘价，成交量使用成交量，RSI 使用自身值，MACD 在自己的图窗内选取最近的有效主线、信号或直方图值。未预热或被裁剪的值不能吸附光标。隐藏模式保留 K 线读数，未来空白不虚构 K 线索引或时间标签。

十字线版本 1 管理颜色、1–3 个 CSS 像素的线宽、实线／虚线／点线及独立的水平／垂直线可见性。专用对话框编辑草稿，应用提交，取消、关闭或 Esc 丢弃。这些偏好不重新适配坐标轴，也不改变图表／指标样式。未吸附数值由宿主调用核心价格／图窗转换，所有图窗保留同一视口。

### 基准线呈现

基准线是以收盘价为基础的主序列，参考价上下分别配置颜色，共用线宽及直线／阶梯连线设置。序列偏好将有效版本 1 字段迁移为版本 2。`baselineSource` 为默认的 `first-visible` 或 `price`；`baselinePrice` 保存 ±1e12 内的整数标准化单位。设置字段显示经过品种缩放的价格，应用前校验单位步长。取消草稿不改变已保存偏好。

首根可见模式使用核心导出的价格轴参考值，固定模式使用配置的原始价格；两者都调用 `price_to_y`，覆盖对数／相对／反转模式。参考价不参与自动范围适配，也不改变行情数据。绘制时将两条分色路径及填充裁剪到投影参考线两侧；反转交换屏幕方向，保留原始价格的高低含义。渐变不透明度从参考线处的 10/255 增至图窗边缘的 40%。参考价位于图窗外时裁剪填充边界；有效对数轴上的非正参考价仍低于所有已绘制价格。填充止于最后一个数据点，保留未来留白。选择和十字线吸附使用收盘价几何，价格图窗内的填充区域可选中。

## 工作台、外观与绘图文档

浏览器工作台将可用视口提供给图表，包含紧凑工具栏、绘图工具栏和可收起的自选／报价侧栏。图表设置与绘图对象／样式使用独立对话框。DOM 布局保留在宿主中。带主题的 DOM 下拉框替代可见的原生选择弹层，使选项采用与页面一致的明暗配色。

`features/appearance/model.ts` 中的外观版本 3 管理主题，独立的主体／边框／影线可见性与上涨／下跌颜色，背景／网格颜色，以及网格／末价线可见性。面板编辑草稿：应用时校验、提交并持久化；取消、关闭或 `Esc` 丢弃草稿。切换主题和重置在应用前只影响草稿，保留指标设置、数据和视口。版本 1、2 偏好迁移至版本 3，起初将主体颜色复制到新增的边框／影线颜色。版本 1 的原深色默认背景 `#131722` 和网格 `#242b3a` 分别变为黑色 `#000000` 和网格 `#202020`。其他自定义颜色保留；旧指标样式字段不属于图表外观。旧 `candleStyle` 字段仅为迁移保留：`zigchart.series` 缺失时，其 `hollow` 值将主序列初始化为空心蜡烛。当前主序列类型和样式由 `zigchart.series` 独立保存。

设置对话框按商品代码、坐标轴和版面分组，同时保持各文档独立。重置会恢复当前主题外观、保留所选序列类型的默认序列样式，以及默认的常规／不反转坐标轴。应用提交三份草稿，指标及十字线偏好不受影响。`features/scales/model.ts` 校验版本 1 坐标轴偏好，只保存请求模式与反转状态，不保存临时原始范围或相对基准。

顶部工具栏集中放置周期、主序列类型、指标、回放和撤销／重做入口。品种、周期、开高低收及指标图例作为 DOM 覆盖层放在图表容器内，共用其背景，不额外占用一行布局高度。`ui/control-feedback.ts` 根据当前绘图、面板和回放状态生成动作文字、无障碍标签及激活／展开状态，不持有或保存业务状态。锁定对象提供解锁动作，提示明确区分受保护的位置／删除操作和仍可编辑的样式。

`features/series/model.ts` 定义独立的版本 2 `zigchart.series` 偏好：蜡烛、空心蜡烛、OHLC 柱、折线、面积或基准线；线条颜色、1–4 的线宽、普通／阶梯插值及面积顶部／底部颜色。未知版本和错误 JSON 使用默认值；受支持版本保留有效字段，将无效字段回退到默认值。主序列变化保留数据、周期、视口、比例、指标和绘图文档。折线、面积与基准线使用已有收盘价及投影收盘坐标；读数和指标仍可使用 OHLC 数据。几何继续采用 ABI v1 的 17 值帧行与 13 值元数据。

折线、面积与基准线的自动价格范围仍包含可见 OHLC 高低价及已启用的叠加指标；切换呈现方式不会只按收盘价重新适配。面积渐变使用配置的顶部／底部颜色，价格图窗顶部的不透明度固定为 40%，底部固定为 10/255；不透明度不是独立偏好。

主序列选择是宿主的临时状态，与绘图选择分开。点击已绘制的序列，将其选中并显示可见控制点；随后点击控制点打开图表设置。`features/series/selection.ts` 使用当前帧的投影坐标及与渲染器一致的 x 位置。折线／面积／基准线控制点采用投影收盘价，蜡烛／OHLC 柱控制点采用开收盘中点。命中与标记裁剪到价格图窗内。选择逻辑不另行计算价格投影或保留帧缓冲区。手势达到 4 个 CSS 像素后转为平移，不能打开设置。点击空白或 `Esc` 清除序列选择；图表获得焦点后，`Enter` 先选中，再次按下才打开设置。品种标题只选中，不打开设置，为蜡烛组件隐藏时保留入口。

右侧栏包含自选成员和当前品种信息。`data/catalog.ts` 定义四个不可变合成条目，提供本地化名称及各自精度。选择器和自选行通过宿主请求切换，成员管理与选择分开。`features/watchlist/model.ts` 按完整目录校验版本 1 文档，保留空列表。仅当前品种接收报价快照，其他行显示报价未加载且不持有订阅。涨跌使用所选周期最新蜡烛的 `close - open`，以 `open` 为百分比基准；开盘价为零时不提供百分比，不推断日涨跌或交易时段报价。

品种选择先校验目录条目并绑定新的 `SampleFeed(symbol)`，再替换稳定会话的数据源。`MarketSession.replaceSource` 使历史、订阅、回放计时器／单步及排队恢复状态失效，清除历史游标，重置回放速度／已开始状态，并暂停加载所选周期。旧回调仍受请求代次保护。宿主清除报价／帧／手势状态及快照截止时间；`RangeController.resetSource()` 也清除缓存截止时间并取消过期适配。元数据 getter 让读数、格式、基准价输入、绘图标签及 PNG 捕获使用当前品种。通用外观、指标配置和图窗布局仍共享；核心接收替换后的标准化序列，不新增品种专用 ABI。

`ui/workspace-layout.ts` 组合侧栏输入与 `pane-resizers.ts`，由 `layout-preferences.ts` 校验版本 3 `zigchart.layout`。版本 1 的价格比例迁移为价格／成交量权重，振荡指标使用默认权重；版本 2 保留原有权重，两者均补充默认顺序 `[0, 1, 2, 3]`。动态分隔条读取已复制的 `Frame.panes`，拖动达到 4 个 CSS 像素后开始，每帧合并增量。上／下键移动相邻边界 8 个 CSS 像素，Home／End 到达核心限制，双击仅恢复相邻两窗的默认比例、保留其总权重。取消恢复手势开始前的权重；添加状态变化在配置核心前丢弃旧边界输入。侧栏为图表列保留至少 220 个 CSS 像素；宽度变化使用核心间距约束，图窗变化使用共享核心几何。

`ui/pane-actions.ts` 负责各图窗控件，读取复制后的几何。核心原子管理价格／成交量／RSI／MACD 标识的排列，移动至相邻图窗时跳过未添加图窗。权重按标识保存，与顺序无关。`paneOrder` 保存在布局文档；最大化是临时状态（`-1` 还原全部启用图窗），仅改变可见掩码。移除当前最大化指标会清除最大化。重排与最大化均不改变视口或锁定范围。重排前取消分隔条输入并恢复预览权重。隐藏价格图窗时，其内容边界导出为 `0/0`，价格刻度为空，价格投影无效；宿主隐藏价格图例、绘图输入和价格轴控件。重排后价格标题留白及覆盖层跟随其实际边界。

指标配置会比较修改前后的启用图窗掩码。新启用成交量、RSI 或 MACD 时，核心清除最大化，让全部启用图窗可见，并保留顺序、权重与时间视口。成员未变、仅修改参数／样式或主图叠加指标时保留最大化。参数／成员变化仍按指标约定重新适配范围。移除正在最大化的指标还原其余图窗；移除其他指标则保留当前最大化。

分析库统一放置指标、策略和脚本，指标分为趋势、成交量、振荡指标和波动率。版本 4 `zigchart.indicators` 迁移版本 1／2／3 设置，保留额外均线并补充关闭的 BB 默认值。版本 1／2 添加空的 `averages` 列表，版本 1 还会补充关闭的 RSI／MACD 默认值。首次使用时不添加任何指标。原有 MA／EMA 和最多六条额外 MA／EMA 各自拥有周期／颜色／线宽；额外 ID `average-1` 至 `average-6` 映射固定数值槽位，不依赖列表顺序。再添加一条会复制原有指标设置；删除额外实例释放其槽位，不改变其他编号。移除内置指标保留设置。成交量拥有颜色／不透明度；RSI 拥有周期／颜色／线宽及参考线（`0 <= lower < upper <= 100`）；MACD 拥有三个周期、主线／信号／直方图颜色及线宽。BB 拥有周期／倍数，独立的中轨／上轨／下轨／填充颜色，1–4 线宽、填充开关及 0–1 不透明度。无效字段、重复或未知额外 ID 会拒绝整份文档。移除释放图例／副图；仅改样式保留范围。策略和脚本仍为明确不可用状态。

水平／垂直线、水平射线、趋势线段、射线、双向延长线、矩形、斐波那契回撤和文字标注由宿主管理，使用稳定 ID 及 UTC 时间／整数价格锚点。`core/drawings.zig` 使用与蜡烛相同的帧变换，批量投影、转换指针位置、按保留 K 线槽位平移锚点，并检测边线／控制点。它以参数形式将延伸线条裁剪到价格图窗，命中测试复用该计算。原始投影锚点与裁剪线段分开，控制点不会移动到图窗边界。对象样式、选中状态、锁定、输入手势、文档校验、持久化和编辑历史属于 TypeScript。`features/drawings/tools.ts` 将单点／两点工具分组，`panel.ts` 用独立对话框呈现对象／样式控件。核心不持有编辑器文档，也不调用浏览器 API。

锚点横向吸附到已保留的真实 K 线，纵向取整数价格单位。未来留白和成交量图窗不能接收锚点。缺少历史锚点时，该图形输出无效几何，直到对应 K 线加载。水平线横贯价格图窗；趋势线是有限线段；矩形通过边线或两个对角控制点选中，填充内部不参与命中。绘图裁剪到价格图窗内，不扩大自动价格范围。按槽位平移会沿真实保留时间戳移动，正确跨越数据间隔。

垂直线只贯穿价格图窗。水平射线从 A 向右延伸；射线从 A 经过 B 延伸（可向左），双向延长线向两端延伸。直线定义在共享价格变换之后，包括对数／反转模式。锚点重合时显示为点，编辑前不推断方向。两个锚点均离开视口时，可见的延伸部分仍能选中。延伸线条支持在未来区域选中，但拖动时指针必须能对应已有 K 线。单锚点编辑同步 A／B。版本 1 文档结构不变，接受新增类型；不认识该类型的旧版本程序会拒绝该文档。

一次完成的拖动或样式修改只产生一步编辑；预览不填充撤销历史，`Esc` 可取消预览。实时 K 线更新不是文档编辑。锁定对象仍可选中和修改样式，但必须解锁后才能拖动或删除。各周期相互隔离，最多保留 256 个图形和 100 步撤销。恢复文档时，撤销／重做历史为空，且没有选中对象；切换周期替换序列，只投影该周期的图形。

可选的 `localStorage` 键包括 `zigchart.locale`、`zigchart.period`、`zigchart.appearance`、`zigchart.series`、`zigchart.scales`、`zigchart.crosshair`、`zigchart.indicators`、`zigchart.layout`、`zigchart.watchlist` 及经过目录校验的 `zigchart.symbol`。`features/instruments/model.ts` 以 `zigchart.drawings:${encodeURIComponent(symbol)}:${priceScale}` 保存绘图，以 `zigchart.baseline:${encodeURIComponent(symbol)}:${priceScale}` 保存固定基准价来源／价格。各绘图文档在内存保留按周期划分的编辑，存储失败也不丢失。绘图版本 1 校验品种、精度、周期、ID、锚点／样式及数量限制；基准价版本 1 校验来源及整数价格。仅原有 ZIG/USD 可以回退到旧 `zigchart.drawings` 及全局基准价字段，不删除旧记录。写入全局序列偏好时将基准价字段重置为默认值，避免跨品种串用原始价格单位。未知或错误偏好安全回退；记录包含设置和绘图，不包含行情数据或已保存回放时钟。

指标线宽为 1 至 4 个整数 CSS 像素，颜色为六位十六进制值，成交量不透明度为 0.1–1。存储访问失败不影响当前会话。

斐波那契对象由 `core/fibonacci.zig` 负责价格、共享坐标轴投影及横向裁剪，命中检测读取同一份比例线。默认插值为 `B + ratio * (A - B)`，反向交换 A／B。可选对数插值仅在有效对数轴且锚点为正值时生效；高价格窄范围使用 `log1p`／`expm1`。比例须为 −10..10 内有限数值；派生价格保留 f64 小数，标签按品种精度显示。有限的屏外比例线仍保留以裁剪区间填充，非有限投影省略；绘图不影响自动适配。

宿主 `chart/fibonacci.ts` 编码数值选项；独立的 `features/drawings/fibonacci-model.ts`、`fibonacci-controls.ts` 和 `fibonacci-render.ts` 分别负责样式、编辑及 Canvas 呈现。每个对象保存 1–24 级比例及其开关／颜色、线型、标签和不透明度。数值在 change、失焦或 Enter 时提交，不替换当前输入框；无效草稿不修改文档。绘图文档版本 1 只允许该类型携带 `fibonacci` 配置。解析器的 1,600 万字符上限容纳各受支持周期中的比例样式；浏览器存储配额可能更小，失败时沿用未保存状态提示。模板仍是后续扩展。

文字类型 8 以文字框左上角为单个数据锚点，编辑时同步 A／B。宿主的 `text-model.ts`、`text-controls.ts` 和 `text-render.ts` 负责纯文本、控件及系统字体换行。绘图文档版本 1 仅该类型必须携带 `text` 配置：非空白、规范为 LF 的内容，最多 1,000 个 UTF-16 代码单元和 20 个显式行；整数字号 10–48、换行宽度 80–640 CSS 像素；粗体／斜体、背景／边框开关与颜色，以及 0–1 背景不透明度。文字使用对象颜色，边框使用对象线宽；自动换行可以产生更多显示行。字段在失焦／change 时提交，内容也可用 Ctrl+Enter 提交，保留输入焦点并复用文档撤销／持久化；锁定仍允许编辑内容及样式。

字体度量保留在浏览器。同一份有界缓存排版用于 Canvas／PNG 绘制，并提供每项两个 f64 的宽／高批次供 Zig 命中检测。核心采用已有共享价格变换和已加载锚点投影，将整个文字框命中区域裁剪到价格图窗，并保持最上层对象优先。文字、字体 API 和文档状态不进入 Zig。历史锚点缺失时等待加载，未来留白锚点仍无效，文字不扩大自动适配范围。固定屏幕位置文字、富文本及图表内直接编辑不在本次实现范围内。

文字整体可从可见文字框内任意位置开始拖动，包括右侧留白中的部分。`drawing_shift` 在 Zig 中转换指针位移：横向按当前共享间距取整为保留 K 线槽位，恰好半格时向远离零方向取整；纵向在原锚点 Y 加指针位移后，通过共享价格轴逆变换计算。两个指针位置都须位于价格图窗内，原始及最终锚点均须对应已加载时间戳。最终价格为 ±1e12 内的整数单位，有效对数轴还要求正价格。操作保留视口／范围并同步文字 A／B，不生成未来时间戳。

临时测量在 `features/measure/` 保存 UTC／整数价格锚点，统计和共享坐标轴投影由 `core/measurement.zig` 负责。两个锚点都必须对应已加载 K 线及有效价格图窗坐标。价差为 `B - A`，百分比为 `(B - A) / abs(A) * 100`，A 为零时不可用。有符号 K 线间隔为 `indexB - indexA`，含首尾数量为 `abs(distance) + 1`；历时采用真实的有符号 UTC 差，保留时间缺口。成交量包含两端，以 `u64` 累加，超过 `2^53 - 1` 时不可用，未完成 K 线贡献其当前累计成交量。扫描量与所选已保留区间长度成正比，不分配内存或重算指标。投影遵守重排后的价格图窗、对数和反转坐标，不改变自动适配。

标尺接受两次点击或至少 4 个 CSS 像素的拖动，Shift 提供快捷入口。完成后退出输入状态，保留数据锚点供重绘。Esc、下次图表点击、工具／导航变化、会话重置和回放起点选择会清除测量。调整尺寸取消未完成输入，但重新投影已完成结果；双指操作优先于待完成测量。该临时覆盖层独立于绘图文档、撤销及 PNG 导出。桥接立即复制新增十值结果，已有 ABI v1 行保持不变。

## 图表图片与全屏

图表图片导出由宿主 `features/export/` 负责。捕获前，工作台取消临时手势并绘制当前完整帧，通过已有核心接口投影已提交绘图。`scene.ts` 复用 `drawChart` 和绘图渲染器及复制后的几何，增加本地化品种／周期、最新已加载 K 线开高低收、UTC／样本标识及可见指标图例，保留当前图窗顺序和最大化状态。不包含十字线、选择状态、未完成编辑及工作台控件。导出新建 Canvas，尺寸采用图表逻辑区域加 56 个 CSS 像素页头和 26 个 CSS 像素页脚，不读取在线 Canvas 的可复用容量。有效像素比受每边 8,192 像素、总计 16,000,000 像素限制，必要时降低输出分辨率。光栅绘制在异步 PNG 编码前同步完成，固定同一时刻状态。文件名清理品种／周期字段；关闭、重试或销毁时释放预览 URL，代次检查丢弃过期编码结果。不增加数据、视口或 Wasm ABI 契约。

`ui/fullscreen.ts` 对 `document.documentElement` 使用浏览器 Fullscreen API，使挂在 body 下的对话框仍属于全屏工作台。已应用状态来自 `fullscreenElement`／`fullscreenchange`，不预先假定切换成功。控件区分忙碌、不支持、请求被拒绝及其他元素占用全屏状态，销毁时释放监听器。全屏尺寸变化沿用现有尺寸调度器。

## 宿主本地化

英文和简体中文的界面呈现完全由浏览器宿主负责。统一的语言选择控制 DOM 文本、Canvas 标签、提示框、加载／状态／错误消息、无障碍标签，以及文档语言、标题和描述。按语言格式化数字和日期只改变呈现：时间戳仍使用 UTC，数值保留原始单位和精度，Zig 引擎和 Wasm ABI 始终与语言无关。

启动时，优先使用有效的已保存语言偏好。否则，从浏览器偏好列表中选择第一个受支持的语言，无匹配时回退为英文。宿主将手动选择的语言以 `zigchart.locale` 为键存入 `localStorage`。读取或写入存储失败不会阻止启动或即时切换语言，但此时无法保存偏好。

切换语言只更新呈现，不重新加载页面或替换核心实例。已加载数据、视口、锁定的纵轴范围、回放进度和订阅、指标可见性，以及进行中的历史请求均保持不变。动态状态必须使用当前语言呈现，包括切换后才完成的请求。面向用户的错误提供本地化上下文，控制台保留原始诊断信息以便调试。两种语言的消息字典应同步维护；标识符和代码注释保持英文。

`chart/format.ts` 按品种缩放系数，为坐标轴、读数和报价提供共享的本地化格式。缩放系数必须是正安全整数，其倒数在 20 位以内终止（质因数仅含 2 和 5）；标准整数值格式精确保留这些小数单位。带小数的指标值与轴刻度按显示精度舍入，紧凑成交量标签有意采用缩写。无效缩放系数抛出错误，不会悄悄把非零单位舍入为零。

手动比例属于核心的临时状态，刷新页面后不恢复。

## WebAssembly ABI v1

所有行字段均以 `f64` 值存储在线性内存中，使用小端字节序。指针表示字节偏移量。在允许范围内，整数时间戳和标准化价格／成交量单位保持精确。数据操作返回状态码，不在 Wasm 内抛出异常。

| `inspect(index)` | 返回可复用的九值行指针；索引无效时返回 0 |
| `transform_view(factor, from, to)` | 在既有视口边界内原子缩放并移动时间锚点分数 |
| `drawing_capacity`, `drawing_input_ptr`, `drawing_output_ptr`, `drawing_strokes_ptr` | 返回 256 个对象的容量上限及借用的输入、锚点、裁剪线段缓冲区 |
| `drawing_fib_input_ptr`, `drawing_fib_output_ptr` | 按绘图槽位索引、借用的固定斐波那契配置与比例线批次 |
| `drawing_text_bounds_ptr` | 按绘图槽位索引、借用的两个 f64 CSS 像素宽／高，供宿主度量的文字框命中检测使用 |
| `drawing_project(count, width, height)` | 使用图表帧变换投影并返回数量，超过容量时返回 -1；无效对象对应输出全零行 |
| `drawing_point(x, y, width, height)` | 返回三值锚点行指针；超出有效价格／数据坐标时返回 0 |
| `measure(timeA, priceA, timeB, priceB, width, height)` | 返回借用的十个 f64 `[x1, y1, x2, y2, priceChange, percent, barDistance, elapsedMs, volume, barCount]` 指针，锚点／几何无效时返回 0；复制后的桥接结果将 NaN 百分比／成交量转换为 null |
| `drawing_translate(time, price, slots, delta)` | 按整数保留 K 线槽位及价格单位平移；返回三值锚点指针或 0 |
| `drawing_shift(time, price, fromX, fromY, toX, toY, width, height)` | 通过共享坐标轴按指针位移移动已加载锚点；返回借用三值锚点行或 0，由桥接立即复制 |
| `drawing_hit(count, width, height, x, y, tolerance)` | 返回二值命中行指针或 0；容差为 0–64 CSS 像素，最后一个匹配对象优先 |

输入行：`time, open, high, low, close, volume`。

帧行（17 个值）：`index, time, open, high, low, close, volume, ma, ema, x, openY, highY, lowY, closeY, volumeY, maY, emaY`。

元数据（13 个值）：`priceMin, priceMax, volumeMax, priceTop, priceBottom, volumeTop, volumeBottom, candleWidth, viewportStart, viewportSpan, totalCount, plotWidth, plotHeight`。

价格轴块（4 个值）：`requestedMode, effectiveMode, inverted, base`。刻度行（3 个值）：`rawPrice, y, displayValue`。这些新增缓冲区保留已有的 17 值帧行和 13 值元数据，价格极值仍为原始单位。桥接在继续调用核心前，随每帧复制刻度并构造普通坐标轴对象。消费者不得通过改变已有列含义来增加图窗或指标。

查询行（9 个值）：`index, time, open, high, low, close, volume, ma, ema`。

图窗行（7 个值）：`id, top, bottom, contentTop, contentBottom, min, max`。振荡指标行（8 个值）：`rsi, macd, signal, histogram, rsiY, macdY, signalY, histogramY`。副图刻度行（3 个值）：`paneId, value, y`。关闭／不可用的振荡指标输出为 NaN。这些新增批次保留所有已有 K 线／帧／查询布局。桥接在暴露 `Frame` 前复制振荡指标／刻度数组并构造图窗对象；功能模块不保留 Wasm 内存视图。

绘图输入行（6 个值）：`kind, timeA, priceA, timeB, priceB, reserved`。类型：0 水平线、1 趋势线、2 矩形、3 垂直线、4 射线、5 双向延长线、6 水平射线、7 斐波那契回撤、8 文字；保留字段为零。绘图输出行（5 个值）：`valid, xA, yA, xB, yB`；单锚点工具将 A 投影到两个点。新增线段缓冲区采用相同的五值布局，输出裁剪端点；不相交／无效线条和矩形对应全零线段行。矩形仍使用锚点几何绘制。继续调用核心前复制两个缓冲区。新增固定缓冲区占 10,240 字节，核心不为单个绘图动态分配内存。锚点行（3 个值）：`time, price, index`。命中行（2 个值）：`batchIndex, handle`，0 表示整体，1 表示 A，2 表示 B。原有 ABI v1 的 K 线／帧布局保持不变。

文字边界输入新增固定 4,096 字节，容纳 256 个宽／高对。桥接每次清空使用的批次，仅填写类型 8 槽位，接受大于零且不超过 65,536 CSS 像素的有限尺寸。无效边界不产生文字框命中，但可见的有效锚点仍可选中。已有几何／线段／帧行保持不变，文字不输出线段；后续核心调用前复制命中结果。

状态码：`0` 成功，`1` 数据无效，`2` 超过容量，`3` 违反顺序要求，`4` 不支持的更新模式，`5` 修正目标尚未加载。TypeScript 桥接检查 ABI 版本，将失败操作转换为错误，应用层错误展示交由宿主负责。

斐波那契新增绘图类型 7，不改变已有行。每个对象配置为 25 个 f64：标志位及 24 个比例；NaN 表示关闭／未使用。标志位为左延伸=1、右延伸=2、反向=4、对数=8、锚点连线=16。输出为 24 行，每行六个 f64：`valid, ratio, rawPrice, clippedLeftX, y, clippedRightX`。无效槽位全零；有限 y 可在价格图窗外，用于填充裁剪。仅类型 7 读写其比例配置／输出；已有线段行表示可选的裁剪锚点连线。固定输入／输出数组新增 346,112 字节，无核心逐对象分配。桥接在后续核心调用前将有效比例线复制为普通对象。

## 内存与生命周期

Wasm 模块使用固定数组保存 K 线、指标、批次输入、帧／坐标轴／刻度输出、查询输出和绘图输入／输出。调用过程中不分配内存，也不扩展线性内存。这样以严格的容量上限换取可预测的固定内存占用。不提供自动淘汰或流式归档；达到容量上限后返回错误，由宿主处理。

指针暴露的是借用的、可复用的缓冲区。桥接先写入完整输入批次，再调用 `apply`；向外提供结果前会复制帧数组，并将查询结果转换为普通对象。调用者不得跨核心调用保留原始内存视图，即使当前实现的内存大小固定。未来若采用可扩展内存，必须在增长后重新创建视图，并保留这一所有权契约。

生成有效帧后，Wasm 边界缓存该帧的价格变换与图窗几何。同尺寸的只读坐标转换直接复用，避免再次扫描可见 K 线。所有数据、视口、比例、指标及布局写操作均使缓存失效，尺寸不同时重新计算。缓存仅持有核心数值状态，不持有宿主内存视图或行情快照；它不会跳过帧生成或指标更新。

每个图表使用独立的 WebAssembly 实例，实例间没有共享的全局图表句柄。释放宿主引用后，该实例的内存可被垃圾回收。浏览器清理还必须取消待完成的历史请求、取消行情订阅，以及断开观察器。宿主通过 `requestAnimationFrame` 最多保留一个待绘制帧。尺寸观察回调请求绘制；Canvas 底层位图尺寸、CSS 几何、核心宽度约束和重绘在同一绘制帧内提交，避免中间出现 Canvas 被清空的帧。

底层 Canvas 绘制图表和绘图对象，透明覆盖层绘制十字线及主序列选择。单一调度器合并整图与仅覆盖层的失效请求，整图重绘优先。仅移动指针时可以复用已复制的帧，只重绘覆盖层；数据、视口、外观、序列、指标、绘图编辑及布局变化请求整图重绘。两层使用相同的已提交尺寸、设备像素比和变换。覆盖层不创建另一个视口，也不保留借用 Wasm 视图。分层本身不能证明性能改善，浏览器测量须包含实际负载。

`chart/surface.ts` 将 Canvas 容量与可见视口尺寸分开。容量以 128 个 CSS 像素为单位增长，视口缩小时复用，超出部分由容器裁剪。每次宽度变化仍按当前逻辑视口更新核心几何并重绘，不拉伸旧图。尺寸观察结果与已提交尺寸相同时，不再请求一次绘制。开高低收及相关文字仅在显示值变化时更新。

图表容器使用 `overflow: clip`，不创建滚动容器：焦点及 DOM 更新不得通过程序滚动将逻辑视口移入未使用的 Canvas 容量。调整尺寸、主题和全屏状态后，多余像素仍须保持裁剪。

## 扩展边界与限制

行情接口是采购数据的集成边界。凭据应保存在未来的行情后端或其他合适的安全宿主中，不应打包进入浏览器发布产物。MVP 样本不依赖外部服务。

当前边界是四个具名图窗、六种内置指标及六条额外 MA／EMA 实例。任意图窗、振荡指标／BB 多实例和公共插件需要显式扩展数值契约，不改变已有列的含义。主序列选项只改变绘制。Python 3 脚本与策略应置于独立的执行宿主中，并定义明确的输入输出；本 MVP 不包含解释器、执行沙箱、订单模型或回测引擎。当前可以逐一选择四个合成样本品种。网络重连、交易时段日历、复权历史、逐笔数据聚合、同时显示多品种的图表和行情数据持久化仍不在已实现的图表范围内。
