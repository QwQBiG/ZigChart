# ZigChart

[English](README.md) | [简体中文](README.zh-CN.md)

围绕可移植 Zig 核心构建的 Web 图表 MVP：**Zig → WebAssembly → TypeScript → Canvas 2D**。

核心负责经过校验的 OHLCV 数据、MA/EMA/RSI/MACD/布林带计算、视口状态、命中检测和图表几何。浏览器负责数据访问、输入、调度、标签和绘制。Canvas 2D 是受支持的架构选择；硬件加速由浏览器管理。

## 当前范围

- 蜡烛、空心蜡烛、OHLC 柱、折线、面积和基准线主序列，以及可选的对齐成交量、RSI、MACD 副图；新偏好默认使用蜡烛且不添加指标。
- MA、EMA、成交量、RSI、MACD、布林带可独立添加，并支持最多六条额外 MA／EMA 实例，分别配置并明确初始化方式。
- 以指针为中心缩放、拖动或键盘平移、十字光标查看和跟随最新数据。
- 常规、对数、百分比、指数化至 100 四种价格刻度，可反转坐标轴，使用易读刻度间隔，支持独立手动缩放及自动适配。
- 时间轴拖动和滚轮缩放，以及具备独立外观偏好的四种十字线模式。
- 批量加载历史数据，以及更新当前 K 线和追加新 K 线。
- 可复现的合成历史数据、历史 K 线回放及独立可暂停的样本更新，页面明确标识为样本数据。
- 英文与简体中文界面可随时切换，包括图表标签和提示信息。
- 全视口工作台，支持收起自选／报价侧栏，通过选中序列设置主题、序列样式、网格和末价线可见性。
- 可调整自选侧栏宽度及最多四个图窗的相邻分隔线，共用时间轴，并按绘图区宽度限制缩放。
- 统一分析库按趋势、成交量、振荡指标和波动率分组；策略和脚本执行尚未实现。
- 同一合成序列提供 1／2／3／5／10／15／30 分钟、1／2／4／6／12 小时、日、周和自然月 K 线。
- 水平／垂直线、水平射线、趋势线段、射线、双向延长线、矩形、斐波那契回撤和文字标注，支持选中、拖动、修改样式、锁定、删除、撤销／重做，以及按周期在本地恢复。

样本并非交易所行情。本项目不包含凭据、采购数据、交易功能、Python 运行时或回测引擎，也不宣称已达到或超越现有图表产品。

## 本地运行

使用 Node.js **22.21.1**、npm **10.9.4** 和 Zig **0.15.2**。Vite **8.3.0** 与 TypeScript **5.9.3** 已在包清单和锁文件中固定版本。在仓库根目录通过 PowerShell 或 POSIX shell 运行：

```text
npm ci
npm run setup:zig
npm run build
npm test
npm run dev
```

打开 Vite 输出的本地地址。`setup:zig` 会将官方编译器下载至 `.tools/` 并校验其校验和，支持 Windows、Linux 和 macOS 的 x64、arm64 平台。也可以将 `ZIG_BIN` 指向 Zig 0.15.2 可执行文件；包装脚本会检查版本。

在 Windows 上使用 `$env:ZIG_BIN = 'C:\path\to\zig.exe'`。本地工具二进制与生成的 WebAssembly 已由 Git 忽略。开发服务器需要 `web/public/core.wasm`；修改 Zig 源码后请重新运行 `npm run build:wasm`。

在 macOS 上，原生测试需要已安装的兼容 Xcode SDK。固定的 Zig 0.15.2 使用 Xcode 26.3：`DEVELOPER_DIR=/Applications/Xcode_26.3.app/Contents/Developer npm test`（请按安装位置调整路径）。CI 仅为当前任务选择此 SDK，不更改系统全局 Xcode 选择。参见 [SDK 兼容性与验证范围](docs/verification.zh-CN.md#自动化检查)。

如需检查生产构建，先运行 `npm run build`，再运行 `npm run preview`。构建产物位于 `dist/`。CI 在 Windows、Linux 和 macOS 上构建并测试，记录执行环境的平台和架构，不执行发布或部署。

## 使用图表

左下角提供 **1天、5天、1个月、3个月、6个月、今年、1年、5年、全部**。选择范围会采用能保持清晰间距的受支持 K 线周期，并在顶部显示该周期。预设结束于最新已知行情快照，不采用电脑当前时间。月份／年份按 UTC 日历计算；全部加载数据源可提供的月 K 历史。

点击旁边的日历入口或按 **Alt+G**，可定位到一个完整 UTC 日期，或选择包含首尾日期的自定义范围。应用后直接请求开盘时间早于范围结束时间的 K 线，无需从当前 K 线逐页向前加载。浏览历史会暂停回放。点击**最新**将历史快照替换为当前快照并保持回放暂停，也可从空历史或加载失败中恢复；图表有数据时，`End` 和双击时间轴提供相同的返回操作。关闭或取消尚未提交的对话框不会改变图表。

日期范围自动选择清晰可读的周期，包含起始日期所在蜡烛，并将结束时间裁剪到提供方快照截止时间。按蜡烛开盘时间选择，保留提供方整根 K 线，因此周／月 OHLC 可能包含请求起点之前或终点之后的日期。工具栏区分无数据、历史不完整、密度限制和加载错误；全部表示可提供的历史，不提示更早起点缺失。手动平移／缩放、返回最新或选择周期会清除范围选中状态。这些 UTC 全天连续样本规则不代表交易所日历，不虚构节假日或周末 K 线。

十字线默认**自由移动**：在同一根蜡烛内上下移动时，光标价格随指针改变，该根蜡烛的开高低收读数不变。可选的**吸附收盘价**对上涨和下跌蜡烛均使用收盘价。设置入口的悬浮提示及无障碍名称显示已应用模式。已有保存模式继续生效；若曾保存磁吸模式，可选择自由移动并点击应用。

顶部工具栏集中放置周期、主序列类型、指标、回放和撤销／重做入口。品种、所选周期、开高低收及指标图例覆盖在图表背景上，不通过独立页头占用绘图区高度。当前品种明确标识为模拟数据。

顶部相机按钮打开固定图表预览，可**下载 PNG**。图片包含按当前顺序／最大化状态显示的图窗、已提交绘图、指标图例、品种／周期、最新已加载 K 线开高低收及 UTC／样本标识；不包含十字线、选择控制点、未完成编辑、工具栏和侧栏。导出采用当前图表区域并增加说明页头／页脚，必要时降低像素密度，使每边不超过 8,192 像素、总计不超过 1,600 万像素。预览打开后图片内容保持固定。旁边的**全屏**按钮将工作台及其对话框展开，状态跟随浏览器，不支持或请求被拒绝时显示反馈。

通过序列控件选择蜡烛、空心蜡烛、OHLC 柱、折线、面积或基准线图。折线、面积和基准线使用收盘价；切换呈现方式不替换数据、不重置视口，也不改变 K 线周期。存储可用时，选择以版本 2 的 `zigchart.series` 偏好独立保存。已有绘图与指标继续使用相同的时间和价格坐标。

使用页眉的 **English / 简体中文** 选择器可立即切换界面语言。首次使用时，按浏览器偏好选择受支持的语言，无匹配时使用英文。浏览器存储可用时，会在本地记住手动选择；存储不可用也不影响当前切换。切换语言会保留已加载的 K 线、视口、锁定的纵轴比例、回放进度和指标可见性。数字与日期采用所选语言的格式，图表时间仍使用 UTC。

拖动或按左／右方向键平移。在图表上滚动鼠标可围绕指针缩放；也可以使用键盘 `+` 和 `-`。按 `End` 或点击**最新**回到当前数据源快照中的最新 K 线。在任一图表区域移动指针可查看同一根 K 线。**更早历史**请求下一页历史数据，靠近左侧边缘时也会自动请求。

打开**回放 → 选择起点**，在任意可见图窗中点击一根 K 线。历史回放包含该根至其周期结束，以可用样本截止时间为上限，初始暂停。播放、暂停、**下一根**、重选以及 **0.25×／0.5×／1×／2×／5×／10×** 速度在所有图窗和周期切换间共用同一截止时间。单步完成当前周期或追加下一根；1× 在两步间等待一秒，计算时间另计。未完成的大周期 K 线排除未来数据。这是合成回放，不是还原的历史逐笔数据。

关闭回放控制会暂停并保留历史位置；**退出回放**恢复当前样本快照并保持暂停。回放仍启用时，**最新**、`End` 和双击时间轴返回当前回放位置。历史回放之外可通过**播放样本更新**单独模拟新的周期内更新。刷新页面不恢复回放位置和速度；未提供可选回放能力的数据源不能使用历史回放。

在右侧价格轴上纵向拖动，只调整价格比例：向上放大、向下压缩，以指针起始高度为锚点。移动达到 4 个 CSS 像素后生效，单击不改变比例。双击该轴或点击**自动／固定**按钮，可重新适配纵轴范围，不移动时间位置。按钮显示当前比例模式；获得焦点后，按上／下方向键围绕价格图中央调整比例。指标副图轴和时间轴不接受这项价格轴手势。

在底部时间轴横向拖动，同样达到 4 个 CSS 像素后生效：向右放大、向左压缩，以绘图区右端为锚点。在时间轴上滚动可围绕指针缩放；双击则跟随最新 K 线并恢复默认右侧留白。这些手势使用图表已有视口与缩放边界。

打开**图表设置 → 坐标轴**，或点击轴旁的价格模式按钮，可选择**常规**、**对数**、**百分比**或**指数化至 100**，并可反转价格轴。核心生成易读的刻度间隔。相对刻度采用中心实际位于视口内的首根 K 线收盘价为基准；百分比为 `(price - base) / abs(base) × 100`，指数化在此基础上加 100。零基准回退为常规。对数模式要求可见数据及范围为正，否则模式按钮提示当前回退为常规。切换模式或反转会保留时间视口、指标副图范围、适配状态及已固定的原始价格范围；自动价格范围使用所选模式的留白规则。偏好独立保存为 `zigchart.scales`。

绘图工具栏的**十字线设置**提供自由移动、吸附收盘价、隐藏、吸附最近开高低收四种模式。折线、面积与基准线在两种吸附模式下均使用收盘价；成交量副图吸附成交量，振荡指标副图吸附所选 K 线处最近的有效指标值。预热值为不可用的 `NaN`，不参与吸附。颜色、线宽（1–3 个 CSS 像素）、实线／虚线／点线及水平／垂直线可见性独立于图表和指标样式。应用后保存 `zigchart.crosshair`，取消或 `Esc` 丢弃草稿。隐藏十字线仍保留 K 线行情读数，未来留白不会产生虚构时间标签。

页眉的周期选择器会加载所选周期、重新计算指标并保留指标可见性开关，回到已加载数据的最新视图；浏览历史时保留其快照截止游标并继续暂停。存储可用时，会在本地记住手动选择的周期。非历史浏览状态下，若原先正在回放，新快照加载完成后会恢复回放，并保留模拟时钟。旧请求和回调不能更新新周期。样本使用 UTC 全天候日历：每周从周一开始，月份按实际自然月边界划分。目前不支持秒级周期或交易所交易时段日历；更改可见范围与更改 K 线周期是独立操作。

点击已绘制的主序列，将其选中并显示可见控制点。折线与面积的控制点位于收盘价；蜡烛和 OHLC 柱的控制点位于开收盘中点。再次点击控制点，打开**图表设置**。拖动至少 4 个 CSS 像素会平移，不打开设置；点击空白处或按 `Esc` 清除序列选择。图表获得焦点后，第一次按 `Enter` 选中序列，再按一次打开设置。品种标题也可选中序列，为蜡烛组件全部隐藏时提供可通过键盘操作的入口。

**图表设置**分为**商品代码**、**坐标轴**和**版面**。商品代码控件随所选序列变化：蜡烛主体、边框、影线各自拥有可见性及上涨／下跌颜色；OHLC 柱可设置上涨／下跌颜色；折线和面积可设置线色、线宽及直线／阶梯连线，面积还可设置顶部／底部填充色。主题、背景、网格及末价线可见性也可配置。点击**应用**提交草稿；**取消**、关闭按钮或 `Esc` 丢弃草稿。深色预设使用黑色背景。选择主题会应用对应图表配色，同时保留其他选项；**恢复默认**恢复当前主题外观、默认序列样式并保留序列类型，同时恢复常规且不反转的坐标轴。指标与十字线偏好保持独立。存储可用时，已应用的偏好保存在本地。

右侧栏包含**自选表**和当前品种信息。从顶部工具栏或**添加商品**打开品种选择器，可选择 **ZIG/USD**、**DEMO:STOCK**、**DEMO:FX** 或 **DEMO:INDEX**。四项均为可复现合成样本，价格缩放系数依次为 100、100、100000 和 10，不是交易所报价。点击自选行切换图表；仅当前品种加载报价，未选中行显示横线。添加／移除成员独立于选择，不重启数据源，空自选表仍有效。成员保存为 `zigchart.watchlist`，经过校验的当前品种保存为 `zigchart.symbol`。显示涨跌是所选周期最新蜡烛的收盘价减开盘价，涨跌幅以该开盘价为基准，不是日涨跌或交易时段涨跌。自选表按钮可收起侧栏。

切换品种会取消之前的数据任务和回放，暂停打开新的样本快照，同时保留所选周期和通用图表／指标样式。各品种分别保存绘图和固定基准价设置；存储不可用时，本次访问中的内存编辑也会保留。原有 ZIG/USD 绘图与基准价偏好可迁移。样本名称不代表真实股票、外汇或指数的交易日历，均使用文档约定的 UTC 全天连续样本。

拖动自选侧栏旁的分隔线可以修改宽度。桌面布局中，侧栏可以占用其余宽度，图表列至少保留 220 个 CSS 像素。该分隔线获得焦点后可用方向键调整，双击恢复默认宽度。下拉选项采用当前页面主题。

价格主图与可选的成交量、RSI、MACD 副图共用一个时间视口和一套帧调度。拖动相邻图窗分隔线达到 4 个 CSS 像素后生效；获得焦点后，上／下方向键每次移动 8 个 CSS 像素，Home／End 移至允许的边界。双击只恢复该相邻组合的默认比例，保留两者合计大小及其他图窗。空间允许时，核心为每个可见图窗保留至少 64 个 CSS 像素；高度不足时均分。版本 3 的 `zigchart.layout` 保存 `paneWeights` 和 `paneOrder`，有效版本 1／2 设置以默认顺序迁移。

各图窗右上角可上移／下移或最大化。价格主图也可移动，标题、OHLC、叠加指标和绘图随之移动。最大化临时隐藏其他图窗，仍使用同一时间视口；还原恢复已有比例和当前顺序。添加成交量、RSI 或 MACD 会自动还原全部启用图窗，让新指标可见。仅编辑参数或样式会保留当前最大化状态。移除正在最大化的指标会恢复其余图窗。重排与最大化保留固定范围。顺序在刷新后保留，最大化状态不保存。只显示副图时，价格绘图工具及价格轴控件不可用。

序列选择、绘图设置按钮和自选表按钮会显示当前状态。回放入口区分开始、暂停和继续，当前不可用的操作会禁用。

打开页眉的**指标与脚本**入口，可用中文或英文搜索分析库。趋势、成交量、振荡指标和波动率分组提供 MA、EMA、成交量、RSI、MACD、布林带。新偏好默认不添加指标。添加 MA 或 EMA 后，**再添加一条**创建拥有独立周期、颜色、线宽、图例和读数的实例；最多六条额外均线可与原有 MA 和 EMA 同时存在。每条新增实例有编号及独立设置／移除入口，移除只删除该实例。移除内置指标则保留其设置、释放图例／副图。版本 1／2／3 的 `zigchart.indicators` 迁移为版本 4，保留已有设置和额外均线，并补充关闭的布林带默认值；版本 1／2 不含额外均线，版本 1 还会补充关闭的 RSI／MACD 默认值。

通过分析库或图表图例中该指标的**设置**，只编辑当前指标。MA、EMA、RSI 各自拥有周期（1–500）、颜色及线宽（1–4 个 CSS 像素）；成交量拥有独立的上涨／下跌颜色和不透明度（10–100%）。RSI 参考线满足 `0 ≤ 下参考线 < 上参考线 ≤ 100`，只影响显示。MACD 可设置快／慢／信号周期（1–500，快周期小于慢周期）、主线／信号线／正值柱／负值柱颜色及线宽。点击**应用设置**提交修改。更改周期或添加／移除指标会重新适配纵轴，不移动横向视口；仅修改样式会保留纵轴比例。**策略**和**脚本**仍是明确不可用的入口，不执行代码或回测。

RSI 默认使用 14 次相邻收盘价变化：以首个完整变化集合的平均涨幅／跌幅初始化，然后采用 Wilder 平滑。初始化区间完全平坦时取 50。MACD 默认周期为 12／26／9，快、慢及信号 EMA 均以各自可用输入的完整周期 SMA 初始化；柱状图为 `MACD - signal`，不乘二。预热值保持 `NaN`。RSI 副图采用固定 0–100 比例，MACD 范围包含零。这些初始化规则是 ZigChart 的约定，不代表与其他平台逐值相同。

**布林带（BB）**叠加在价格主图：收盘价 SMA 加减总体标准差（除数为 `N`）的指定倍数。默认周期 20 根、倍数 2；周期为 1–500，倍数为 0.1–10。前 `N - 1` 个值不可用。中轨、上轨、下轨和填充颜色独立，可设置 1–4 个 CSS 像素线宽、填充开关和 0–100% 填充不透明度。悬停读数显示三轨数值。添加 BB 保留图窗最大化状态，不创建副图。BB 多实例、其他数据源／中轨均线、偏移及独立指标周期尚未实现。

打开左侧**线条工具**：水平线、水平射线和垂直线单点定位；趋势线段、射线和双向延长线两点定位。矩形使用独立工具。射线从第一点经过第二点向外延伸，可朝时间轴任一方向；双向延长线向两端延伸。水平射线向右延伸，垂直线贯穿价格图窗。在已有价格 K 线上放置锚点。使用指针工具选中图形，可拖动整体或端点、修改颜色和线宽、锁定或删除。一次完成的编辑对应一步撤销；`Esc` 取消未完成的绘图或拖动。图形使用 UTC 时间与整数价格作为锚点，因此平移、缩放、调整尺寸及加载历史后仍能对齐。每个周期有独立文档，最多 256 个图形和 100 步撤销。有效的本地文档可在刷新后恢复；撤销历史和选中状态不恢复。可在未来留白中选中延伸线条，但不支持在那里创建锚点或开始拖动。

从左侧绘图工具栏打开**绘图对象与样式**。独立对话框可选择当前周期的图形，包括视野外的对象，然后修改样式、锁定／解锁，或在解锁后删除。选中已锁定对象时，按钮显示**解锁选中绘图**并提供对应提示：位置和删除操作受保护，颜色与线宽仍可编辑。锚点所需历史尚未加载的图形仍保留在此列表中；只有加载对应 K 线后，才能将其投影到图表上。

选择左侧工具栏的**文字**，在价格图窗的已加载 K 线位置点击，即可放置文字框并打开编辑器。纯文本支持最多 1,000 个字符和 20 个显式行，80–640 CSS 像素的自动换行宽度、10–48 字号、粗体／斜体，以及可选背景和边框。对象颜色用于文字，线宽用于边框。双击文字框可再次打开对话框。离开字段时提交修改，也可用 Ctrl+Enter 提交文字。左上角锚点跟随时间和价格，可通过可见文字框选中和拖动，包括延伸到右侧留白中的部分；移动后的锚点仍须对应已加载 K 线。文字参与按周期保存、撤销／重做及 PNG 导出；锁定保护位置和删除，内容与样式仍可编辑。不接受空白文字；固定屏幕位置文字、富文本及图表内直接编辑尚未实现。

使用左侧工具栏的**测量**标尺，或选择指针工具后按住 **Shift** 在价格图窗点击／拖动。依次点击起点和终点，或拖动至少 4 个 CSS 像素后松开。临时结果显示有符号价差／百分比、K 线间隔及含首尾数量、真实 UTC 历时，以及包含两端 K 线的成交量。起始价格为零时不提供百分比，成交量超过安全整数精度时显示不可用；未完成末根采用当前成交量。锚点必须对应已加载 K 线，图窗重排后仍遵守此约定，未来留白及副图不能接收锚点。完成后保留结果，直到下次图表点击、Esc、切换绘图工具或导航；调整窗口尺寸会重新投影已完成结果。测量不进入已保存绘图、撤销历史或 PNG 导出。

默认视图在最新蜡烛右侧保留约 20% 的绘图区宽度。向左拖动蜡烛可扩大留白，最多将最新蜡烛放到绘图区中央。空白区不会生成虚构 K 线。最新蜡烛可见时，实时追加会保留当前右侧留白；按 `End` 或点击**最新**恢复默认留白。历史数据不足时，左侧边界可能限制精确定位。

MA／EMA 首次添加时使用周期 20。核心最多保留 100,000 根 K 线。视口最少显示 10 个 K 线槽位，最大跨度按绘图区宽度限制，目标是相邻蜡烛中心至少间隔 6 个 CSS 像素，绝对上限为 2,000 个槽位。每个 WebAssembly 实例使用固定容量存储。实现行情提供方前，请先阅读下方的接口约定。

平移保持蜡烛间距及纵轴范围不变，松开鼠标后也会保留。有效缩放、点击**最新**或按 `End` 会重新适配自动价格及指标范围；RSI 保持 0–100，在缩放边界继续输入则保留锁定范围。新进入视野但超出固定范围的数据会裁剪在各自图窗内。时间标签锚定 UTC 时间并随对应蜡烛移动；缩放时可调整标签密度。

基准线图分别为参考价上方／下方的收盘价着色。在顶部工具栏选择**基准线图**，再打开序列设置，可选择首根可见收盘价或固定品种价格，修改上下颜色、线宽及直线／阶梯连线。应用保存草稿，取消丢弃；已有版本 1 序列偏好迁移时保留样式。数据适配器可发送已加载时间戳的显式修正；原子校验和订阅规则见[数据契约](docs/data-contract.zh-CN.md)。

**斐波那契回撤**位于**线条工具 → 斐波那契**分组。放置两个锚点后，在**绘图对象与样式**中编辑该对象。每个对象可保存 1–24 个独立颜色／开关的比例（−10 到 10），以及左右延伸、反向、锚点连线开关、比例／价格标签、线型和背景不透明度（0–0.6）。数值编辑在失焦或 Enter 时提交，可撤销。比例 0 对应 B，1 对应 A；反向交换两者。默认基于原始价格计算，仅在有效对数图上启用对数比例时采用对数计算。坐标反转改变位置，不改变价格。派生价格保留小数精度，标签按品种精度显示；拥挤的标签会省略。设置独立于图表外观和其他绘图。模板和未来时间锚点尚未实现。

在触摸屏上，从绘图区内放置两个触点，可双指缩放共享时间轴；移动双指也会移动其时间锚点。第二个触点会取消未完成的单指拖动或绘图预览。松开一个触点后，需抬起全部剩余触点再开始新手势；第三个触点会暂停导航。单指沿用已有选择、绘图和平移行为。惯性滚动和长按十字线追踪尚未实现；物理触摸设备及移动浏览器验证仍待完成。

## 项目结构

| 路径 | 职责 |
| --- | --- |
| `core/` | 平台无关的图表引擎、Wasm 入口及原生测试 |
| `web/src/main.ts`、`web/src/app/` | 应用入口、工作台组装及图表输入路由 |
| `web/src/chart/` | Wasm 桥接、图表类型、Canvas 绘制及时间标签 |
| `web/src/data/` | 规范行情类型、品种目录、样本提供方、周期规则及请求／订阅生命周期 |
| `web/src/features/instruments/` | 当前品种及按品种保存的绘图／基准价状态 |
| `web/src/features/analysis/` | 独立指标设置及分析库 |
| `web/src/features/appearance/` | 经过校验的外观模型和草稿设置对话框 |
| `web/src/features/drawings/` | 绘图文档、编辑器、绘制及对象／样式对话框 |
| `web/src/features/measure/` | 基于核心测量输出的临时标尺交互及结果呈现 |
| `web/src/features/export/` | 图表图片组装、有界 PNG 编码、预览及下载 |
| `web/src/features/range/` | UTC 日期／预设选择、清晰周期策略、导航对话框及加载控制器 |
| `web/src/features/replay/` | 历史回放控件及状态呈现，时钟由会话和提供方管理 |
| `web/src/features/series/` | 主序列偏好及基于当前投影帧的选择 |
| `web/src/features/scales/`、`web/src/features/crosshair/` | 独立的坐标轴／十字线偏好、设置及交互反馈 |
| `web/src/features/watchlist/` | 品种搜索／选择、独立自选成员管理及当前报价呈现 |
| `web/src/ui/` | 本地化、工作台布局、浏览器原生全屏、主题下拉框及公共样式 |
| `tests/` | 针对构建后的 Wasm 桥接及宿主数据行为的测试 |
| `scripts/` | 固定版本的编译器安装、构建包装脚本及本地测量 |
| `docs/` | 架构、行情接口约定、验证流程及参考资料 |

实现约定见[功能范围](docs/feature-map.zh-CN.md)、[架构](docs/architecture.zh-CN.md)、[数据约定](docs/data-contract.zh-CN.md)和[验证流程](docs/verification.zh-CN.md)。设计调研及许可边界记录在[参考资料](docs/references.zh-CN.md)和[第三方说明](THIRD_PARTY.zh-CN.md)中。贡献者请先阅读[贡献指南](CONTRIBUTING.zh-CN.md)和 [AGENTS.md](AGENTS.md)。

## 状态与许可证
